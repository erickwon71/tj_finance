# 분류 과제

입력 파일의 각 절(`=== Sxxx | 원문 N행 ===` 로 시작)은 한국 상장사 재무보고서 파싱 프로젝트의 규칙 문서 한 절이다(뒷부분이 생략됐을 수 있다).
용어: 계층2 = `report_lines` 테이블(DART 보고서 원문에 인쇄된 값을 그대로 싣는 곳). 계층3 = std·`layer3_cell_corrections` 등 계층2 를 읽어 표준 계정으로 바꾸고 값을 보정하는 곳.
원칙 R0-2: 계층2 에는 인쇄된 값만 싣는다. 부호 복원·숫자 교정·빈칸 채움·행 이동·다른 원천으로 덮어쓰기는 모두 계층3 의 일이다.
예외: 인쇄 **표기를 읽는 법**(깨진 천단위 구분자 `.`, 셀 안 '원' 접미사, 단위 선언과 실제 단위가 다른 것이 증명된 섹션의 단위 해석 — R158·R158-b·R202·R218·R169·R207·R238 계열)은 "다른 값을 만드는 것"이 아니라 "읽는 법"이므로 계층2 다.

## 판정 순서 — 위에서부터 묻고 처음 "예"인 곳 하나만 고른다

| 순서 | 질문 | 예이면 category |
|---|---|---|
| 0 | 절 제목이 R0, R0-1, R0-2, R2, R6, R9 이거나, `0. 규칙 색인`·`부록` 인가? | `principles` (색인·부록은 `index`) |
| 1 | 판정 문장(“~한다/~하지 않는다”로 앞으로의 처리를 정하는 문장) 없이 경위·측정·배치 실행 기록만 있는가? | `case_log` |
| 2 | 인쇄된 숫자와 **다른 값**을 만드는가? (부호 뒤집기·숫자 교정·빈칸 채움·행 이동·다른 원천 값으로 덮어쓰기) | `layer3` |
| 3 | 원문에서 무엇을 어떻게 **읽어** 계층2 에 싣는가? (표·열·기간·단위 판정, 표기 해석, 행·표 인식, 무엇을 싣지 않는가) | `layer2` |
| 4 | 계층2 를 std·계층3 테이블로 어떻게 바꾸는가? (계정 매핑, 정정본 병합, 정규화) | `layer3` |
| 5 | 데이터를 쓰지 않고 맞는지 판정만 하는가? (Gate B, face_audit, verify, 기계대조, 감사 스크립트) | `audit` |
| 6 | 수집 대상·파이프라인 배선·백업·운영 | `ops` |

추가 표시 `migrate`: category 가 순서 2 로 `layer3` 인데 본문상 그 처리 코드가 계층2 파서(`fin2/extract`, `parser/`, `report_lines` 적재)에 있으면 `yes`, 아니면 `no`.

## 출력

절마다 정확히 한 줄, 탭 구분, 입력 순서대로, 머리줄 없이:
`Sxxx<TAB>category<TAB>step(0~6)<TAB>migrate(yes/no)<TAB>근거 30자 이내(한국어)`

다른 설명·요약은 쓰지 않는다. 생략된 부분은 추측하지 말고 보이는 글로만 판단한다.
