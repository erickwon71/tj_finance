# 검증 판정 시험 v2 (D=DB 값, S=원문 값. 단위 언급 없으면 표시 단위 백만원)

1. SCE 자기주식 열의 한 변동행: 원문 셀 '-', DB 에는 그 셀 줄이 없음. 같은 행의 다른 열은 모두 일치.
2. 원문 셀 "1.234.5"(마침표가 두 개라 숫자로 읽을 수 없음). CSV 금액 빈칸, 원문값 칸에 "1.234.5".
3. IS 표 선언 (단위: 백만원). 기본주당이익 원문 1,234. CSV 단위 '원', 금액 1,234.
4. IS 매출액: 원문 선언 백만원, 원문 1,234. CSV 단위 '천원', 금액 1,234,000.
5. SCE 이익잉여금 열 당기 블록: 기초 100, 변동 a 원문 10 / DB -10, 변동 b 원문 5 / DB 25, 기말 원문·DB 115. 이 셀들이 든 다른 항등식은 없음.
6. SCE 이익잉여금 열: 기초 100, 변동 a 원문 10 / DB -10, 변동 b 원문·DB 10, 기말 원문·DB 100. 다른 항등식 없음.
7. SCE 이익잉여금 열: 기초 100, 변동 원문·DB 60, 기말 원문 (150) / DB 150. 같은 필링 BS 같은 날짜 '이익잉여금' 행 150.
8. SCE 이익잉여금 열: 기초 100, 배당 원문 10 / DB -10, 기타 변동 원문·DB 5, 기말 원문·DB 100. 배당 행의 행 합계(구성요소 합 = 합계 열)는 DB 값으로 닫히고 원문 값으로는 안 닫힘.
9. SCE 이익잉여금 열: 기초 100, 변동1 원문·DB 20, 변동2 원문 (10) / DB 10, 기말 원문·DB 110.
10. IS 같은 자리: 원문 계정명 '자기주식처분이익' 값 (30), DB 계정명 '자기주식처분손실' 값 30.
11. IS 매출액: 원문 당기 1,000 · 전기 900, DB 900.
12. IS 표 선언 천원. 매출액 원문 1,234, CSV 단위 천원·금액 1,234,000.
13. 슬롯에 필링 A(기계대조 stale)와 필링 B(기계대조 mismatch, value 2건)가 있다. 슬롯 전체에서 할 일은?
14. fixed 이슈 재확인: error_type missing_row. 재적재 후 원문 그 자리에 DB 행이 생겼고 값이 원문과 같다.
15. fixed 이슈 재확인: error_type extra_row. 재적재 후에도 그 DB 행이 그대로 있다.
16. ⑥ 계산: SCE(원 단위 표) 기말 이익잉여금 1,234,567,890, 같은 필링 BS(천원 단위 표) 이익잉여금 1,234,568. 이 둘은 닫힌 것인가?
17. 전체 대조 중: IS 원문에 전기 열에만 '중단영업손익 50' 행이 있고 당기 칸은 빈칸. DB 에 그 행이 없다.
18. 한 필링에 value 발견 12건. 대표 3건을 웹뷰로 확인하니 3건 모두 C3 이고 증상은 셋 다 sign_flip.
19. 한 필링에 value 발견 8건 + missing_row 발견 4건(합 12건).
20. 같은 필링 SCE 에서 전기 블록(기말 2022.12.31) '연차배당' 행 이익잉여금 열 원문 (100) / DB 100, 당기 블록(기말 2023.12.31) '연차배당' 행 이익잉여금 열 원문 (120) / DB 120. 각 이슈의 column_label 은?
21. 정정본 필링(기계대조 no_source, 적재 행 있음): 원문(웹뷰)에는 연결 현금흐름표만 있다. DB 에는 이 rcept 로 연결 BS·IS·CF 가 적재돼 있다(CF 는 원문과 일치).
22. 한 필링에 value 발견 11건. 대표 3건 중 2건은 C3 sign_flip, 1건은 C3 unit_scale.

각 사례에 한 줄로 답하라: `번호 | 적용한 규칙(C1/C2/C3/I1/I2/I3 등) | 행동 | 등록할 이슈(error_type × 건수, 없으면 -)`
20번은 행동 칸에 두 column_label 을 적는다.
