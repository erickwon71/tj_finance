# CF 가 탐지되는데 DB 에 없는 2015+ 필링 16건 — 원인 분류 (2026-09-29)

배경: R195 스캔에서 "BS/IS 는 있는데 CF 가 없는 (필링, 기준)" 2015+ 43건 중, 탐지기가 CF 표를 찾는 16필링을 조사했다.
판정 방법: 필링별 원문 마크업·섹션 구조 확인, 같은 필링 추출 결과의 `col_index`/`context_fiscal_year` 확인, 적재 이력(`filing_loads`,
`report_line_load_progress`)과 형제 필링(정정공시) 조회, 9월 16일 시점 코드 스냅샷(`d55a255`, `ced578b`, `5bcd304`)으로 재추출.

**핵심 함정**: 지금 코드로 추출하면 CF 행이 나오는 필링이 많다. 그러나 그 행은 대부분 col_index 1·2(전기·전전기)뿐이다.
`store_report_lines` 는 당기(col_index=0)만 적재하므로 DB 에는 0행이다. 코드 변경 때문이 아니다(9월 16일 이전 코드 3개 시점도 같은 결과).
