### R202
판정일치: 예
초안 오류: haiku — 없음 / sonnet — 없음
> **규칙** 셀의 토큰이 정확히 둘이고, 앞 토큰이 1~2자리 무콤마 정수, 뒤 토큰이 콤마 그룹을 가진 숫자이며, 앞 토큰 자릿수 + 뒤 토큰 첫 그룹 자릿수 = 3 이면 두 토큰을 이어붙여 한 숫자로 읽는다(`1 73,918` → 173,918). 마크업 형태(SPAN 쌍·기타 태그·순수 텍스트 공백)는 가리지 않는다. 그렇지 않으면 종전대로 None 이다.

> **하지 않는 것** `5 1,234,567`·`12 345,678`·`1 234` 는 이어붙이지 않고 종전대로 None 이다.
> **코드** `parser/common/amount_normalizer.py::parse_amount`, `_R202_SPLIT_LEADING_DIGITS`

### R205
판정일치: 아니오 — 같은 행에 숫자열이 같은 정수 칸이 둘 이상일 때: haiku 는 "하나뿐"이라 복원 안 함, sonnet 은 "하나 있을 때만"이라 복원 쪽(불명확으로도 표시).
초안 오류: haiku — "하나뿐"은 원문에 없는 한정(원문은 "하나 있을 때만"); 계층2 원칙과의 충돌 주장은 원칙 목록이 R158(마침표 구분자·정확한 짝 복원)을 "읽는 법"으로 허용하므로 성립하지 않음; 두 호출 지점 누락 / sonnet — 없음
> **규칙** 셀이 `^[(-]?\d{1,3}\.\d{3}(,\d{3})+$` 꼴(첫 구분자만 마침표, 나머지 쉼표)이면 소수로 읽지 않는다. ① 같은 행에 숫자열이 정확히 같은 정수 칸이 하나 있을 때만 그 정수로 복원한다. ② 못 찾으면 R160 대로 결측으로 두고 원문 텍스트는 `raw_amounts` 에 남긴다. 주당손익 행은 기존대로 제외한다.
> **판정 예** 이랜시스 `20180515000412` CF 별도 `1. 투자활동으로 인한 현금유입액` 셀 `69.792,290` → 같은 행에 숫자열이 같은 정수 칸이 있을 때만 69,792,290, 없으면 결측(종전엔 소수 69.79229 로 읽어 70 적재). LG씨엔에스 `20220516001347` `3.193,161` → 같은 처리(종전엔 3, 천원 표에선 3193).
> **하지 않는 것** 접두사·꼬리 0 맞춤으로 짝을 만들지 않는다(추측) — 접두 짝은 복원하지 않는다. 주당손익 행은 건드리지 않는다. 일반 금액은 대상이 아니다. 마침표 뒤가 숫자뿐인 꼴은 R160 가드(`_DOT_GROUPED_RE`) 소관이다.
> **코드** `table_extractor._DOT_THEN_COMMA_RE`, `unresolved_dot_cell_indices`, `_repair_dot_grouped_cells` (호출 지점 `extract_rows`, `report_lines` SCE 그리드 경로가 같은 두 함수를 씀)
> **충돌·불명확** 같은 행에 숫자열이 정확히 같은 정수 칸이 둘 이상일 때의 처리는 본문에 없다("하나 있을 때만"만 적힘).

### R207
판정일치: 예
초안 오류: haiku — NH투자증권 CF 미확정을 "10배 조건 불충족"으로 묶음(원문은 NH 는 실제 백만원·기존 테스트 고정, 10배 조건 불충족은 콜마 원본 CF_S 1섹션만); 네오크레마 "충돌"은 정정 문단으로 정해지므로 충돌 아님 / sonnet — 네오크레마 공존을 충돌로 남김(정정이 나중이라 정해짐)
> **규칙** 같은 회사·같은 basis 의 다른 필링(±1 회계연도) 당기 `자산총계` 중앙값 대비, 이 필링의 선언단위(adecimal<0) `자산총계` 가 `RATIO_SUSPECT_MIN`(=100)배 이상이고 선언 배수의 0.1배 이상이면 그 필링·basis 를 의심 섹션으로 지명만 한다. 확정은 R169 그대로(같은 회사 다른 필링에 정확히 같은 금액이 `MIN_HITS`건 이상, 다른 k 는 ≤1건이고 10배 차)이고, 확정된 섹션만 증명된 실제 단위로 읽는다(숫자는 그대로, `unit_source=proved_unit`).
> **판정 예** 콜마비앤에이치 원본 `20240516002083`: 표머리 `(단위: 천원)`, 매출액 셀 `119,858,420,057`(원 단위 풀 금액) → 선언대로면 ×1,000(별도 매출 119조원) → 지명·확정 후 원문 값과 일치, `proved_unit`. 네오크레마 `20231226000346`: 연결 BS `(단위 : 천원)`(10426행) 아래 자산총계 `77,318,521,415` → 같은 R207 결함(정정 문단, 8섹션 overrides 병합).
> **하지 않는 것** 지명만으로는 값을 바꾸지 않는다(측정 신호는 후보 발견용). 자산이 실제로 급증한 회사는 증거가 없어 건드리지 않는다(R6). 미확정 38섹션(NH투자증권 CF 실제 백만원, 콜마비앤에이치 원본 CF_S 1섹션 10배 조건 불충족)은 그대로 둔다. 콜마비앤에이치 정정본 `20240516002340` 별도 기타포괄손익 누적 -539,838 은 R154 대로라 결함이 아니다. 2012~2014 필링 4건·2010 이전 PDF 비율 이상치는 범위 밖·미조사.
> **코드** `fin2/audit/unit_self_contradiction.ratio_suspects`(`suspect_rcepts` 합집합), `scripts/unit_self_contradiction_scan.py`, `collect_new._report_unit_self_contradiction`, `fin2/extract/data/unit_self_contradiction_overrides.json`
> **충돌·불명확** R207 절에는 `MIN_HITS` 숫자가 없다(같은 입력의 R238 절은 R169 조건을 hits(k) ≥ 3 으로 적었다).

### R238
판정일치: 예
초안 오류: haiku — 2차(같은 문서) 증거·웹뷰 인쇄본 원천을 규칙에서 빠뜨리고 충돌 줄로 보냄(본문에 정해져 있음), 충돌 줄 불필요 / sonnet — 2차 증거를 규칙에서 빠뜨리고 "임계값 미기재"를 충돌로 둠(2차 증거도 2번 확정 조건으로 판정)
> **규칙** 표머리가 원(`adecimal = 0`, `unit_source='declared'`)인 필링·basis 의 당기 `자산총계` 가 같은 회사·같은 basis ±1 회계연도 다른 필링 당기 `자산총계` 중앙값의 1/100 이하이면 지명만 한다(지명만으로는 값을 바꾸지 않는다). 지명된 basis 의 섹션(BS/IS/CF/SCE)은 선언 배수가 전부 1 이어도 판정한다: 원문 숫자 A 에 k ∈ {1, 1,000, 1,000,000} 을 곱해 같은 회사 다른 필링 적재값과 정확히 같은 금액 수 hits(k) 를 세어, hits(k) ≥ 3 이고 다른 k 는 전부 ≤ 1 이면서 hits(k) ≥ 10×그 값일 때만 확정한다. k = 10⁶ 확정은 R238 로 지명된 섹션에서만 허용하고, 타 필링 증거가 모자라는 섹션은 같은 문서·같은 basis 의 이미 확정된 섹션 금액에 그 섹션의 확정 k 를 곱해 증거로 쓰며, 확정분만 overrides 에 기록해 그 섹션의 모든 금액 행을 k 배로 읽는다(숫자는 그대로, `proved_unit`, `adecimal = −log10(k)`); 원천은 본문 XML, 없으면 웹뷰 인쇄본이다.
> **판정 예** SK네트웍스 `20171114002669` 연결 BS 자산총계 셀 `7,814,615`, 표머리 `(단위 : 원)` → hits(10⁶)=5~37, hits(1)=hits(1000)=0 → k=10⁶ 확정 → DB 7,814,615,000,000(CSV 단위 백만원, D = S, `unit_scale` 로 등록하지 않음). HD현대 [기재정정] `20191114002747` 웹뷰 인쇄본 `(단위 : 원)`, 자산총계 `25,475,706,904`, hits(1000)=24~85, hits(1)=hits(10⁶)=0 → k=1,000 확정.
> **하지 않는 것** 지명 밖 섹션에서 10⁶ 이 우세하면 선언 백만원이 맞다는 뜻이라 확정하지 않는다(NH투자증권 CF). 증거가 k=1 을 가리키면 `declared_correct` 로 바꾸지 않는다(이웃 오염 가짜 지명, 삼성공조 2011형). 주당이익 행은 섹션이 `proved_unit` 이어도 ×k 하지 않고 원 단위(`unit_source='declared'`, `adecimal=0`) 그대로다. 미확정(증거 부족)이면 선언대로 두고 `defer`(노트 `R238 미확정: 증거 부족`), 짐작으로 단위를 바꾸지 않는다(R6). 검증·수정 쪽: `proved_unit` 셀의 `unit_scale` 이슈는 F7-a `no_fix`(노트 `R238·근거 rcept`); 표머리 원·숫자 백만원인데 `proved_unit` 이 아닌 셀은 F7-c 가 아니라 스캔 `--apply` + `batch reload` 대상. 데일리는 보고만 한다(`logs/unit_self_contradiction_pending.jsonl`). 2015 이전 지명 23건은 다루지 않았다.
> **코드** `fin2/audit/unit_self_contradiction.py`(`_UNDER_RATIO_SQL`·`under_ratio_suspects`·`_decide(allow_mega)`·2차 증거 ×k), `fin2/extract/report_lines.py::_unit_override`, `fin2/extract/review_csv.py::_note`, `scripts/unit_self_contradiction_scan.py --apply`, `fin2/extract/data/unit_self_contradiction_overrides.json`, `docs/verification/verify_prompt.md`(용어 S)

### R183
판정일치: 아니오 — 행 이동에서 합계 열을 판정에 넣는지(haiku 는 "합계 열 제외" 누락), 같은 행 교정 셀이 여럿일 때 함께 적용한 상태로 판정하는지(haiku 누락)에서 갈림.
초안 오류: haiku — 행 이동 "구성요소 열(합계 열 제외)"·값 교정 "같은 행 여러 셀 함께 적용"·행 제외 "부호복원 체인 전에 뺀다"·셀 채움 "합계 열 1개일 때 Σ비합계 = 합계" 누락; R184 일반화를 충돌로 둠(R183 자체 판정은 정해짐) / sonnet — "허용오차 '정확히 닫힘'만"·R184 를 충돌로 둠(정해짐)
> **규칙** 계층3 보정은 `sce_source_defects` 의 rcept 예외목록(`_VALUE_FIXES`·`_ROW_MOVES`·`_ROW_DROPS`·`_CELL_FILLS`)에 등재된 SCE 원문 오류에만 적용하고, 등재 항목도 매 적재마다 표 자신의 항등식으로 다시 증명해 안 되면 경고만 남기고 손대지 않는다. 값 교정: 원래 값으로는 열 롤포워드와 행 항등식이 둘 다 깨지고 교정값으로는 둘 다 닫혀야 한다(같은 행 교정 셀이 여럿이면 함께 적용한 상태로 판정). 행 이동: 그 행이 채우는 구성요소 열(합계 열 제외)마다 원래 블록·대상 블록이 이동 전엔 둘 다 안 닫히고 이동 후엔 둘 다 정확히 닫혀야 하며, 대상 row_order 가 이미 차 있으면 거부한다. 행 제외: 기대값이 정확히 일치할 때만 부호복원 체인(R162…R163) 전에 빼고, 체인 뒤 `verify_row_drops()` 가 그 블록 구성요소 열이 정확히 닫히는지 보아 안 닫히면 되돌린다. 셀 채움(보강): 합계 열에만 인쇄된 변동행의 구성요소 열 셀을, 채우기 전엔 그 열 블록 잔차가 정확히 −값이고 행 항등식(합계 열 1개일 때 Σ비합계 = 합계)이 깨져 있으며 채운 뒤엔 둘 다 정확히 닫힐 때만 합계 셀을 복제해 추가하고(값 교정 직후·부호복원 체인 전), 셀이 이미 있으면 손대지 않는다.
> **판정 예** 동진쎄미켐 `20170515004289` 연결 비지배지분 원문 6,768,899,293 → 6,768,889,293 (6,708,169,143 + 90,585,596 − 29,865,446). 에코프로 `20180402002079` 연결 SCE '전환상환우선주행사' 2016 블록 → 2015 블록 빈 같은 라벨 자리로 row_order 이동, 별도 SCE 2015 '지분법이익잉여금변동' 104,092,712 행은 적재하지 않음. 현대위아 `20240320001675` 별도 SCE 2021 '배당금의 지급' 이익잉여금 열(원문 U+3000) → −18,593(백만원) 채움.
> **하지 않는 것** 같은 패턴을 자동 탐지 규칙으로 일반화하지 않는다(R6) — 합계 열 단독 변동행 전수 스캔 567필링·652행은 측정만 하고 등재하지 않았다(이후 일반화는 R184, 이 입력 밖). 증명이 안 되면 낡은 교정값으로 덮어쓰지 않는다. 행 이동 판정에서 합계 열은 뺀다(무관한 sign_flip 혼입). R159 셀 텍스트 치환·R162 계열(부호만)로는 이 문제를 다루지 않는다.
> **코드** `fin2/extract/sce_source_defects.py`(`_VALUE_FIXES`·`_ROW_MOVES`·`_ROW_DROPS`·`_CELL_FILLS`·`verify_row_drops()`), 배선 XML `extract_report_lines()`(R162 직전 + R163 뒤 사후검증)·XBRL `extract_report_lines_xbrl()` 반환 직전

### R189-b
판정일치: 예
