# 금융섹터 revenue 표준 — 마스터 참조 (살아있는 문서)

> **금융업(일반 제조업과 IS 구조가 다른 업종)의 revenue 표준·결정·잔여를 한곳에 누적한다.**
> 섹터별 census 로 결정이 쪼개지므로, 흩어진 핸드오프 대신 **이 문서 하나가 단일 출처**다.
> 마스터 허브 [`rearchitecture_4layer.md`](rearchitecture_4layer.md) 에서 링크. 코드=`fin2/layer3/industry_profiles.py`.
> 진단도구: `scripts/diag_financial_revenue.py --induty <KSIC>` (신 코드 revenue vs std_v3 대조).
> 최종 갱신: **2026-07-25** (증권·여신전문·다올 재빌드+원문대조 완료 / **잔여 KSIC census 종결·프로파일 불필요**)

## 0. 방법론 (census)
금융사는 모집단이 작아(**섹터당 1~63사**) 전수조사가 가능·타당하다. 각 KSIC 섹터를 진단도구로
전수 실행 → revenue 산출 경로(프로파일 compose / 일반매퍼 / NULL)와 값을 firm×연도로 검증한다.
**표준 확정 후 재빌드(`build_std_v3 --all`) 해야 std_v3 에 반영**된다(프로파일은 빌드시 적용).

## 2. 잔여·엣지 (섹터별)

### 증권 (66121) — 19사
- **순영업수익 공식이 판관비 총계를 요구**. 대부분(17사) 클린 판관비 보유 → net 성립·시계열 일관.
- **★대신증권·한화투자증권 = gross_fallback(플래그)**: 판관비를 단일 총계 없이 **항목화**(인건비+
  기타판매비와관리비…) + **대신은 부동산(분양) 겸영** → 순영업수익 신뢰추출 불가. 공시 영업수익
  총계로 폴백하고 `industry_lines.revenue_basis="gross_fallback"` 로 표시(사용자 결정 2026-07-24,
  option 1). basis 불일치가 가시화되므로 앱/스크리너에서 식별 가능.
- 소형 별도-only 회사(유화·코리아에셋·한양)는 basis 폴백(연결 없으면 별도)으로 정상 처리.
- 현대차: 정본이 net형식 → 공식 정상(op+판관비).

### 여신전문·저축은행 (64913·64911·64132) — 4사
- **영업수익 총계 있음**: 메이슨캐피탈(0.025조) → 프로파일이 total_labels 로 defer, 일반매퍼가 총계
  선택(변경 없음). ★현재 census 표본에서 다올(661 오분류·아래) 외 총계보유사는 메이슨뿐.
- **총계 없음(성분만)**: 삼성카드 3.935조(이자2.03+수수료1.81+기타0.09)·한국캐피탈 0.510조(이자0.47+
  수수료0.04)·푸른저축 0.089조(이자0.08+수수료0.002+기타0.008). 전부 구 std_v3 대비 대폭 상향(정정).
- 신규 여신전문사(할부·리스 등) 편입 시 KSIC 확인 후 `induty_prefixes` 확장.

### 다올투자증권 (KSIC 661 오분류 → 증권) — corp override
- 실질 증권사인데 **661(금융지원서비스)로 코딩**돼 66121 증권 프로파일 미적용 → 일반매퍼가 수수료수익
  0.176조 오선택(공시 영업수익 총계 1.71조 무시). **`CORP_INDUTY_OVERRIDE`(00156859→66121)** 로 증권
  표준 강제 → **0.298조(net=영업이익+판관비)**. 661 의 결제/핀테크사(NHN KCP·헥토·카카오페이·글로벌
  텍스프리)는 실제 비증권이라 대상 아님. (사용자 결정 2026-07-24)

### 보험·은행 — 회귀 확인
- norm() 견고화(전각 마침표 `．`·깨진 주석접미사) 변경은 **공용**이나 회귀 0: 생보11·손보1·은행4·
  지주63 + 비금융(반도체61·소매14) = **154사 전량 신=구 일치**(2026-07-24). 증권만 의도 변경.
- 여신전문/다올 추가 후 재회귀(2026-07-24): 은행4·생보11·손보1·지주63 = **전량 신=구 유지**(무영향).

## 3. 코드 지도 (`fin2/layer3/industry_profiles.py`)
- `norm()` — 라벨 정규화(번호·전각/반각 문장부호·주석접미사 제거). **공용** — 변경 시 전 섹터 회귀필수.
- `RevenueProfile` 필드: `induty_prefixes`·`signature_labels`·`total_labels`·`claim_total`·`net_op_formula`.
- `net_op_formula=True` → revenue=영업이익+판관비(증권). `_OP_INCOME_LABELS`·`_SGA_LABELS`·`_OP_REVENUE_TOTAL`.
- 프로파일: `INSURANCE`·`BANK`·`SECURITIES`·`CREDIT_FINANCE`. `NO_REVENUE_CORPS`(한국금융지주형).
- `CORP_INDUTY_OVERRIDE` — corp 단위 KSIC 오분류 교정(다올투자증권 661→66121). `apply_revenue_profile`
  가 induty 대신 오버라이드 induty 로 프로파일 선택. combine.py 호출부에 `corp` 인자 배선 완료.
