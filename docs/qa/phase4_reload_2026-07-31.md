## 3. 재적재로 드러난 별개 결함 — 셀 병합 (사용자 판단 대기)

원문 `20200814000694` 16.담보로 제공된 자산:

```
차입처   담보제공자산            채권최고액   차입금종류        차입금액
신한은행 시화공장 토지,건물,기계  19,080,000  구매자금시설자금  500,0001,302,500
기업은행 …                       16,800,000  시설자금…         170,000511,000
```

**한 셀에 두 숫자가 구분자 없이 붙어 있다**('500,000' + '1,302,500'). `parse_amount` 의
R1 은 **공백으로 나뉜** 다중 숫자만 거부하고, R3 상한이 1경이라 5,000조가 그대로 통과한다.

- **F1 이 만든 문제가 아니다** — 구 규칙도 같은 값을 넣었다(선언 `'(원화단위 : 천원, …)'` 은
  구 정규식도 매칭했다). 이번 검증이 처음 드러낸 것뿐이다.
- 규모: `|value| ≥ 1,000조` **4,112 행 / 666 filing**. 그 아래 구간(100조~1,000조 86,837 행)
  에는 삼성전자 자산총계(≈500조) 같은 **실값이 섞여 있어** 함부로 자를 수 없다.
- 선택지: ① R3 상한을 1경 → 1,000조로 조인다(한국 상장사 최대 총자산의 2배 여유)
  ② 콤마 그룹 문법 위반(4자리 그룹 등)을 병합 신호로 본다 ③ 현행 유지.
  ①은 재추출이 666 filing 뿐이라 수 분이면 끝난다.
