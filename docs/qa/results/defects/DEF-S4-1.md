## 기대결과
- 매뉴얼 근거: `docs/user_manual_app.md` §2.3(연결/별도 전역 토글)·§3.2①(재무제표 표는 표시옵션의 기준(연결/별도)에 따른 원 단위 값을 표시) — 별도를 선택하면 **별도재무제표 기준 수치**가 표시되어야 한다. 별도 데이터가 없을 때만 연결로 자동대체되며 이 경우 반드시 "※ 별도 데이터 없음 → 연결 표시" 각주가 노출되어야 한다(§2.3, 부록 B 주2).
- 코스메카코리아 2023 CQ2 별도 매출액 기대값(DB `calendar_financials` separate 행, Gate B로 원본 보고서와 100% 일치 검증됨): **66,695,451,338원**

## 실제결과
- 별도를 선택했음에도 화면·CSV 모두 **연결(consolidated) 기준 수치**가 표시됨. 코스메카코리아 2023 CQ2 매출액이 **115,651,142,905원**으로 표시되는데, 이는 DB `calendar_financials`의 **consolidated** 행 값과 소수점 이하까지 정확히 일치한다(별도 행 값과는 73.4% 차이).
- "별도 데이터 없음 → 연결 표시" 대체 각주(DS-4)는 노출되지 않음 — 즉 앱은 스스로 "정상적으로 별도를 보여주고 있다"고 인식한 채 실제로는 연결 값을 노출 중.
- 동일 패턴이 **파인테크닉스(연간x별도)**에서도 재현: 2016년 매출액 UI=216,325,020,984 = DB consolidated 216,325,020,984(별도 행은 189,787,081,424). 2021년 매출액 UI=433,367,771,780 = DB consolidated 433,367,771,780(별도 행은 186,657,748,601).
- 코스메카코리아는 **12개 분기(2023 CQ2~2026 CQ1) 전부**에서 매출액·영업이익 모두 이 패턴으로 재현(총 24건 diff). 파인테크닉스는 **연간 2016~2025 중 다수 연도**에서 재현(19건 diff). 일부 연도(예: 파인테크닉스 2022, 2024)는 그 해 연결≈별도(자회사 실적이 미미)라서 diff%가 작게(<1~5%) 나와 우연히 허용오차(0.5%) 근처거나 초과이나 패턴은 동일(연결값이 표시됨).

## 영향 범위
- shard4(416사) 스윕에서 **현재 확인된 것은 2사(코스메카코리아, 파인테크닉스)**이나, 두 회사 모두 "별도" 선택 시 예외 없이 매 기간 연결값이 노출되는 구조적 패턴이라 코드 수준의 원인(예: `used_stmt`/캐시 키가 별도 요청에서도 연결 시리즈를 반환하는 버그, 혹은 Streamlit `st.cache_data` 캐시 키에 연결/별도 구분자가 누락된 회귀)일 가능성이 높음.
- **주의**: `value_diffs.csv`는 허용오차(0.5%) 초과 건만 기록하므로, 연결≈별도인 회사(자회사가 없거나 미미한 회사)에서는 동일 버그가 있어도 진단이 잡히지 않을 수 있음 → 실제 영향 범위는 이보다 넓을 가능성. 감리 단계에서 `used_stmt`/캐시 로직을 코드 레벨로 확인하고, 다른 shard(1/2/3/5/6)에서 동일 패턴이 발견되는지 교차 확인 권고.
- 영향받는 지표: 본 스윕은 매출액·영업이익만 대조했으나(METRIC_MAP), 동일 데이터 소스(캐시된 series)를 쓰는 다른 모든 재무 항목(자산·부채·순이익 등, 밸류에이션·지표 탭 등 series 재사용 화면 전체)에도 파급 가능성 있음.
