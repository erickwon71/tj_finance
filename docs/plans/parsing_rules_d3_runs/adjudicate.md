# 과제: 두 요약 초안을 원문 규칙과 대조해 확정안 만들기

입력 세 파일:
- `batchN.md` — 규칙 원문 전문(`=== R번호 | 파일:줄 ===` 로 시작하는 절들). **이것이 정답의 근거다.**
- `out_haiku_N.md`, `out_sonnet_N.md` — 같은 규칙에 대해 두 모델이 각자 쓴 요약 블록(`### R번호`).
요약 블록의 작성 지침은 `instructions.md` 에 있다(먼저 읽는다).

## 규칙마다 할 일
1. 두 초안의 **규칙** 문장이 원문 기준으로 **같은 셀에 같은 판정**을 내리는지 본다(문체·길이 차이는 무시, 조건·예외·한정어 차이만 본다).
2. 각 초안에서 원문과 다른 것을 찾는다: 원문에 없는 조건 추가, 원문 조건 누락, 기각·폐기된 변형을 규칙에 넣음, 계층(상태 줄의 적용 계층) 오기.
3. 원문에 충실한 **확정 블록**을 쓴다(지침의 형식 그대로). 두 초안에서 원문에 맞는 부분을 취하고, 원문만 근거로 고친다. 새로 지어내지 않는다.
4. 원문만으로 판정이 정해지지 않는 곳(원문 안 모순, 빠진 조건)은 확정 블록의 **충돌·불명확** 줄에 남긴다. 초안이 "충돌"이라 적었어도 원문을 읽어 실제로 정해지면 지운다.

## 출력 (한 파일, Write 도구로)
규칙마다:
```
### R번호
판정일치: 예 | 아니오 — (아니오면 한 줄: 어느 조건에서 판정이 갈리는지)
초안 오류: haiku — … / sonnet — … (없으면 "없음")
> **규칙** …
> **판정 예** …
> **하지 않는 것** …
> **코드** …
> **충돌·불명확** … (있을 때만)
```
다른 설명은 쓰지 않는다. 입력 순서대로.
