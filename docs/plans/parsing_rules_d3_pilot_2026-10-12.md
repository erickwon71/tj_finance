# D3 시범 — 규칙 머리 요약 블록 (2026-10-12, 검토용)

> 상태: **시범안. 규칙 파일에는 아직 넣지 않았다.** 형식·문장을 검토받은 뒤 나머지 규칙에 적용한다.
> 목적: 모델(Haiku/Sonnet)·worktree 가 같은 규칙에서 같은 판정을 내리게, 각 규칙 머리에 **판정에 쓰는 문장만** 따로 둔다.
> 본문(발견 경위·측정·배치 기록)은 그대로 아래에 남고, 판정은 이 블록으로 한다.
> 모든 문장은 해당 규칙 본문에 이미 있는 내용이다(새 결정 없음). 괄호 안 위치는 근거 문장.

## 형식

```
> **상태** … · **적용 계층** …          ← D2 에서 이미 넣은 줄
>
> **규칙** 명령형 1~3문장 (“~한다 / ~하지 않는다”)
> **판정 예** 입력 → 결과 (원문 실례)
> **하지 않는 것** 비슷해 보이지만 이 규칙이 아닌 경우
> **코드** 파일::함수 · **테스트** 파일
```

## R158 — 마침표로 깨진 천단위 구분자 (계층2, 읽는 법)

> **규칙** 금액 셀이 `숫자,숫자.숫자` 꼴(마침표가 천단위 구분자 자리)이고, 그 숫자열이 **같은 행의 정수 칸** 숫자열의 접두사이며 남는 꼬리가 전부 0 이면, 그 정수 칸의 자릿수로 읽는다. 짝이 없거나 후보가 둘 이상이면 읽지 않는다(R160 으로 간다).
> **판정 예** `'42,549.493'` 옆 칸 `'42,549,493'` → 42,549,493 · `'10,590,556.9'` 옆 `'10,590,556,900'` → 10,590,556,900 · 코오롱 `20260515002605` 한 행 `'393,211,876'`·`'393,211.876'` → 393,211,876
> **하지 않는 것** 주당손익 행(라벨이 EPS 이거나 `(단위 : 원)` 을 스스로 선언한 행)은 대상이 아니다 — 원 단위 소수가 정상이다(R158 후속 EPS 라벨 가드). 짝 없는 마침표 셀을 반올림·절삭하지 않는다.
> **코드** `parser/xml/table_extractor.py::_repair_dot_grouped_cells`

## R160 — 해결 안 된 마침표 셀 (계층2)

> **규칙** R159·R158 을 거친 뒤에도 마침표-구분자 꼴(`_DOT_GROUPED_RE`)로 남은 금액 셀은 숫자로 읽지 않는다. 주당손익 행과 라벨이 `(단위 : 원)` 을 선언한 행은 제외한다. 천원·백만원 선언 표라는 이유로 예외를 두지 않는다.
> **판정 예** `10,937,873.5`(짝 없음) → 값 없음 · 에스티아이 `20260515000677` `['희석당기순이익 (단위 : 원)', '343.0']` → 343 (라벨이 원을 선언, 대상 아님)
> **하지 않는 것** 절삭(`int(float())`)·반올림(R157) 값을 싣지 않는다 — 10³ 배 틀린 값이 검산을 통과한다.
> ★**알려진 차이(결정 대기)**: R160 본문·현행 코드는 "그 셀을 **적재하지 않는다**"이고, R0-1 4항은 "**행은 싣고 값 NULL + `value_raw`**"를 목표로 적는다. R0-1 "정합화 대기" 표에 이미 올라 있다(현행 463셀·129필링). 그래서 시범 문장은 "숫자로 읽지 않는다"까지만 썼다 — 어느 쪽으로 맞출지는 사용자 결정.

## R218 — 한 셀에 두 번 이어붙은 EPS (계층2, 읽는 법)

> **규칙** EPS 행에서 ① 행 인라인 단위가 원이고 ② 라벨에 EPS 항목이 정확히 둘이며 그중 정확히 하나가 '경상' 또는 '계속' 항목이고 ③ 그 행의 **모든** 금액 셀이 소수 없는 정수이며 앞 절반 = 뒤 절반이면, 모든 셀을 절반으로 읽는다. 하나라도 어긋나면 행 전체를 그대로 둔다.
> **판정 예** 오성첨단소재 `20040813000222` `기본및희석주당경상이익기본및희석주당순이익` `182182`·`341341` → 182·341
> **하지 않는 것** `1. 기본주당이익 및 희석주당이익`(값 하나를 한 라벨로 찍음) · 기본/희석 쌍 · 앞뒤가 다른 이어붙임(`394391`) · 라벨에 기간 값(`\d원`·`제N기`)이 박힌 행.
> **코드** `fin2/extract/report_lines._emit_eps_lines` (`_eps_label_has_two_items`, `_halve_doubled_eps_amounts`) · **테스트** `fin2/tests/test_r218_eps_doubled_cell_split.py`

## R154 (+R116) — Q1 누적 공란에 3개월 값 (계층3, 빈칸 채움)

> **규칙** 계층2 는 Q1 누적 칸이 공란인 행을 싣지 않는다(인쇄된 그대로). 계층3 은 그 표가 스스로 "3개월 = 누적"을 증명할 때 — 3개월·누적이 둘 다 실값인 행이 하나 이상이고 그 행들이 **예외 없이** 같은 값 — 또는 R116 목록의 필링일 때, 3개월 값을 누적 값으로 채운다(`layer3_cell_corrections` fill).
> **판정 예** 기아 `20240516001819` 연결 IS `매출액 26,212,851 | 26,212,851` (증인) · `기본주당이익 7,125 | (공란)` → 계층2 없음, 계층3 fill 7,125
> **하지 않는 것** 반례가 하나라도 있으면(3개월 ≠ 누적) 그 표는 채우지 않는다. Q1 이 아니면 채우지 않는다(R156). 한쪽이 공란인 행은 증인이 아니다.
> **코드** `fin2/extract/report_lines._q1_cum_fill_on` · STEP `R154_q1_cum_fill` · **테스트** `fin2/tests/test_r154_q1_self_proving_cumulative.py`

## R118 — 헤더 기간라벨 중복 오기재의 열 교정 (계층2, 열의 기간 판정)

> **규칙** 표 헤더가 서로 다른 물리열에 같은 기간라벨을 중복 기재한 필링은, 회계항등식 역산이나 사용자 원문대조로 확정한 `(rcept_no, statement, basis) → {열 위치: 기간 순번}` 예외목록대로 열의 기간을 정한다. 목록에 없는 필링은 판정불가(R6).
> **판정 예** 신영증권 `20220615000399` 별도 CF 헤더 `제67기`·`제67기`·`제66기` → 첫 그룹 = 당기(제68기). 교정 후 영업+투자+재무+환율 = 순증감, 기초 + 순증감 = 기말이 닫힌다
> **하지 않는 것** 숫자를 바꾸지 않는다(어느 열이 어느 기간인지만 정한다). 일반 규칙으로 추측하지 않는다.
> **코드** `fin2/extract/report_lines.py::_R118_DUPLICATE_PERIOD_LABEL_FIX`, `_apply_duplicate_period_label_fix`

## 시범에서 드러난 것

1. **본문끼리 어긋나는 곳이 요약을 쓰다 보면 드러난다** — R160(셀 미적재) vs R0-1 4항(행 적재 + NULL, 정합화 대기 표에 있음). 요약 블록을 쓰는 단계에서 이런 차이를 목록으로 모아 결정을 받는 것이 D3 의 부수 효과다.
2. 요약 1건에 본문 정독이 필요하다(R162 처럼 353줄짜리도 있다). 모델에 맡기면 다시 해석 차이가 생길 수 있으므로, 적용 방식 제안: **모델이 초안 → 같은 규칙을 다른 모델이 독립 초안 → 두 초안의 "규칙" 문장이 같은 판정을 내리는지 비교 → 다르면 사용자 결정 목록**(B 단계와 같은 방식).
3. 대상 우선순위 제안: 검증 판정에 직접 쓰이는 규칙(verify_prompt 가 인용: R0-2·R158·R158-b·R160·R169·R202·R205·R207·R218·R238) → 계층3 보정 규칙(as_printed STEPS 37개) → 나머지.
