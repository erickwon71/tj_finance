# 검증 판정 시험 v4 — 보고서 유형별 경계 사례 (D=DB 값, S=원문 값)

1. XBRL 정정본 SCE. CSV 비고 `열=미처분이익잉여금(미처리결손금) [member]`, 원문 열 머리 가장 아래 칸 `미처분이익잉여금(미처리결손금)`. 이 둘은 같은 열인가?
2. 삼성전자형 SCE: 블록 행 순서 `2018.01.01 (기초자본)` → `회계정책변경` → `수정후 기초자본` → 변동행들 → `2018.12.31 (기말자본)`. 앞 블록 기말 `2017.12.31`. ② 이월 계산에 쓰는 뒤 블록 기초 행은? ① 롤포워드의 기초 행은?
3. 원문 기초 행 계정명이 `수정 후 기초자본`(띄어쓰기 있음). ① 에서 이 행을 기초로 쓰는가?
4. IS 기본주당이익: 원문 `0.04`, CSV 금액 `0.04`, CSV 단위 원.
5. 두산밥캣형: 원문 선언 `(단위 : 천, USD)`, 매출액 원문 3,456,593. CSV 단위 `USD`, 금액 3,456,593, 비고 `표시통화(USD) 미환산`.
6. SCE 에 열 이름 `주석` 인 DB 셀이 5개 있고 금액(30, 12, 7, 30, 12)으로 적재돼 있다(원문은 주석 번호). 어떻게 등록하나? 롤포워드 계산에 넣나?
7. BS: 자산총계 1,000, 부채총계 행 없음, `자본과부채총계` 1,000, 자본총계 400.
8. BS(백만원): 자산총계 1,000, 부채총계 600, 자본총계 398. 모두 D=S.
9. SCE(백만원) 이익잉여금 열: 기초 100 + 변동 3개(10, 20, 5) = 135, 기말 137. 모두 D=S.
10. SCE(백만원) 이익잉여금 열: 기초 100 + 변동 1개(10) = 110, 기말 113. 모두 D=S.
11. CSV `구분` 이 `★원문만` 인 CF 줄: 금액 빈칸, 원문값 `1,234`.
12. 원문 셀 `1.234.5`(읽을 수 없음)인데 그 셀이 DB 에 없다.
13. 원문 셀 `1.234.5` 가 들어 있는 열의 롤포워드는 어떻게 판정하나?
14. 3분기 IS: 헤더 `3개월 | 9개월`. DB 매출액 900. 원문 3개월 300, 9개월 900. 어느 열과 비교하나, 결과는?
15. SCE 열 순서가 `자본 [member] · 자본금 [member] · 이익잉여금 [member]`(XBRL, 합계가 맨 왼쪽). ⑤ 는?
16. 기계 value 발견에 `block_end: "2023.12.31 (기말자본)"`, `db_col: "자본>이익잉여금"` 이 있다. 이 셀 이슈의 column_label 은?
