## 영향 범위
- shard2(416사) 전수 스윕 중 이 패턴이 재현된 기업은 **삼영이엔씨(00288343) 1건**뿐(분기×별도 조합). 같은 기업의 분기×연결 조합에서는 CV-6("default metrics not found")가 별도로 FAIL했으나 value_diffs에는 잡히지 않음 — 같은 기업이 두 조합에서 서로 다른 이상 징후를 보여 이 기업의 재무 데이터/렌더링 경로 전반에 문제가 있을 가능성을 시사.

## 비고
- 이 값불일치가 (a) 앱의 CSV export 경로가 연도/분기 컬럼을 잘못 매핑하는 앱버그인지, (b) DART 원본 데이터 자체의 정정·중복 버전(예: `calculated_at DESC LIMIT 1`이 오래된/정정 전 버전을 집어오는 DB 적재 문제)인지, (c) 이 회사 특유의 결산월 변경·合弁 등 특수 이력 때문인지 QA 단계에서는 확정하지 못함. "동일 UI값이 다른 연도에 반복" 패턴은 CSV 파싱 컬럼 오프셋 버그 가능성도 배제할 수 없어, 개발자가 브라우저에서 직접 CSV를 열어 원본 대비 확인 권장.
- 같은 기업의 CV-6 FAIL(분기×연결)은 `docs/qa/results/shards/sweep_all_companies_shard2.csv`에서 corp_code=00288343 검색으로 확인 가능.
