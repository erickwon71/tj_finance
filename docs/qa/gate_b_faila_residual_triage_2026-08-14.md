것이라 오탐 위험이 낮게 보이지만, 전체 PASS 모집단 대상 회귀 실측은 아직 안 했다).
**R16과 동일한 curated-override 방식**(이 5개사만 등재, `_resolve()`가 아니라 별도
additive path 필요 — `bs.trade_payables`는 `ADDITIVE_CANON`이 아니므로 새 분기 필요)
으로 좁혀서 설계해야 함. **미착수, 승인 필요.**

스케일 처리 로직 확인 필요. **std_v3/combine.py 수정 대상 아님.**

재발 가능한 카테고리임이 이번에 추가로 확인됨(총 3개사 이상). **std_v3/combine.py
