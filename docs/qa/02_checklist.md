# TJ Finance 시각화 앱 — 전기능 테스트 체크리스트 (담당자 실행본)

> 기준 스펙: `docs/user_manual_app.md`. 방향/전제: `01_test_direction.md`.
> 각 항목 실행 후 **결과(P/F/NA)** 와 **증거(스크린샷 경로/비고)** 를 채운다. FAIL은 `03_defect_template.md`로 결함 등록 후 DEF-ID를 증거란에 기입.
> §A(전수 자동 스윕) 결과는 CSV(`results/*.csv`)로, §B(기능) 결과는 이 표 또는 `results/checklist_run.csv`로 기록.

범례: 결과 = **P**(pass) / **F**(fail) / **NA**(해당없음) / **BLK**(선행조건 미충족). 적용 = **ALL**(전수 2,554사) / **SMP**(엣지케이스 표본) / **1**(1회 검증).
