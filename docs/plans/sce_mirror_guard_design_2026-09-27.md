# 설계 — SCE 거울해(mirror solution) 가드 (2026-09-27, G-A·G-B(i) 구현 = PARSING_RULES R190, G-B(ii) 보류)

> 배경: 인계 1-1(M 집합 부분 뒤집기 필링 재적재) 2015+ 측정 중 발견. 사용자 결정 "거울해 가드 먼저".
> 관련 규칙: PARSING_RULES R162-b(이월잔액) · R162-e(롤포워드 단일셀) · R186(자기일관성) · R187(날짜 앵커).

## 1. 측정 요약 (M 집합 2015+, 현재 코드 `12dca70` 재추출 vs DB)

- M 2015+ 906필링 중 값이 바뀌는 필링: XML 295 + XBRL 13 = 308.
- 두 기준 판정기(롤포워드 + 행 항등식)가 악화·혼합으로 잡은 10셀과, BS 에서 같은 금액이 **기존 값** 부호로 발견된 셀을
  전부 원문·BS·행 항등식으로 대조했다. 실제 악화는 **6필링**이다(`docs/qa/sce_m2015_excluded_2026-09-27.txt`).
  나머지는 새 값이 맞았다(서울평가정보 IS −588,900,975 · 앱클론 BS +9,857,758,929 · 디알텍 BS 자본총계 38,714,030,838 등).
- 재적재 후보 302필링: `docs/qa/sce_m2015_reload_targets_2026-09-27.txt` — **이 가드가 정해진 뒤** 재측정해서 쓴다.

## 3. 기각한 안 — 행 항등식 되돌리기(G1)

"약한 증거 뒤집기(R162-e·이월잔액)로 인쇄 상태에서 성립하던 행 항등식이 깨지면 되돌린다."
스크래치 monkeypatch 로 두 위치에서 측정했다(M 2015+ 307필링).
- R162 직후 판정: 배당·자기주식취득·순손실 등 맞는 뒤집기를 대량으로 되돌림(형제 열은 뒤의 R162-d/R189 가 고친다).
- 체인 끝(R189 뒤) 판정: 52셀 되돌림. 악화 3건(20191114000117·씨에스베어링·제닉스)은 잡지만, **맞다고 확인한 셀도 되돌림**
  (디알텍 2셀·신성델타테크 704,186,511·티이엠씨씨엔에스 무상증자·케이아이엔엑스 배당).
- 이유: 원문이 한 행 전체에서 괄호를 **일관되게** 빠뜨리면 인쇄 상태로도 행 항등식이 성립한다. 그래서 "인쇄 상태에서 성립"은
  부호가 맞다는 증거가 못 된다. → 되돌리기가 아니라 **잔액 셀에 외부 앵커를 더 주는** 방향으로 간다.

## 4. 제안

### G-A. R187 날짜 앵커를 분기·반기 보고서 BS 로 확장 (근본 수정, 위험 낮음)
- 지금 `load_prior_balances` 는 `report_type='annual'` BS col 0 만 읽는다. 그래서 비교 블록의 분기말·반기말 잔액
  (씨에스베어링 2021.03.31, 넵튠 2020.06.30)에는 앵커가 없다.
- 변경: 같은 회사의 **모든 정기보고서**(분기·반기·사업) BS col 0 을 `period_end_date` 별로 읽는다(최근 N기간, 날짜별 최신 rcept).
  기존 가드(그 날짜 BS 자본총계 = SCE 합계 열)는 그대로 둔다.
- 예상 효과: 씨에스베어링 2021 블록은 기말 앵커(−4,067,083,224)로 R162 가 잔액을 음수로 확정하고 변동 +3,426,150 을 유지한다.
  넵튠은 2020.06.30 자본금 앵커(+)가 R162-e 의 기말 뒤집기를 막는다(기초 가짜 괄호 자체는 남는다 — §6).
- 비용: 로더 쿼리 하나. 추출기는 그대로 DB-free.

### G-B. 잔액 행 자체 증명 앵커 (새 증거 유형 — 사용자 판단 필요)
- 조건: SCE **잔액 행**(기초/기말)의 자본총계 셀이 그 날짜 BS 자본총계와 같다(= R187 가드 통과). 이 행의 행 항등식이
  - (i) 인쇄 그대로 모두 성립 → 그 행의 모든 0 아닌 셀에 **인쇄 부호**를 앵커로 준다.
  - (ii) 인쇄로는 깨지고, 양수 셀 **하나만** 음수로 바꾸면 모두 성립하며 그런 셀이 유일 → 그 셀에 **음수** 앵커.
- 근거: 자본총계가 BS 와 일치하므로 행 전체 일관 누락(§3 의 착시)은 불가능하다. 합계 셀도 같이 틀려야 하는데 그러면 BS 와 어긋난다.
- 예상 효과: 제닉스(기말 행 합계 = BS 자본총계, 인쇄 성립 → 기타자본구성요소 + 앵커 → 이월잔액 뒤집기 거부),
  20191114000117(기초·기말 행이 col7 음수에서만 성립 → 잔액 음수 앵커 → 변동 +250,400,208 유지).
- ★(ii)는 R162-d 의 "이중증거 셀만"(사용자 결정 2026-09-25)과 성격이 겹친다. 두 번째 증거로 "BS 자본총계 일치"를 인정할지는
  사용자 판단 사항이다. (i)만 먼저 하는 안도 가능하다(20191114000117 은 못 고침).

## 5. 측정 계획 (구현 후, 커밋 전)
1. G-A, G-B 를 각각 켬/끔으로 재추출: M 2015+ 307필링 + 악화 6필링 → 6필링 해소 여부, 새로 바뀌는 셀 수.
2. 2015+ SCE 필링 전체(또는 무작위 1만 필링 표본)로 켬/끔 → 바뀌는 셀을 BS·IS·직전 보고서로 판정(순환 금지: G-A 로 쓴 BS 를
   G-A 판정 기준으로 다시 쓰지 않는다 — 판정은 다른 날짜의 BS·IS·행 항등식으로).
3. 결과를 PARSING_RULES 에 R190(가칭)으로 기록 → 회귀 테스트(6필링 형태) → 커밋·push → M 2015+ 재적재(1-1 마무리).
