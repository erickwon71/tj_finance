## 0. 핵심 결론 — 같은 지표가 여러 재무제표에 있을 때 어디서 가져오는가

계층2 전량적재로 드러난 사실: **같은 값이 BS/CF/SCE/주석에 중복 존재**하고, 그 중 일부는
원문 오류가 있다. 계층3 은 지표마다 **1차 출처를 고정**해 오류난 출처를 피한다.

| 지표군 | 1차 출처 | 근거 | 보조 |
|---|---|---|---|
| **자본 잔액** (이익잉여금·자본금·자본총계·지배/비지배지분) | **BS** | SCE 기말잔액에 원문오류 집중(아래 §1). BS 는 같은 값을 정상 보유 | SCE(교차검증용) |
| **현금 주주환원** (배당지급·자기주식 취득·유상증자 현금유입) | **CF** | 흐름값이라 부호·단위 오류가 잔액보다 적음. 배당·자사주취득은 CF·SCE·주석 3중 존재(값 일치 확인) | SCE·주석 |
| **자본 내부 이동** (자기주식 **소각**·자본항목 재분류·이익잉여금 처분) | **SCE**(보조) | 현금이 안 움직여 CF 에 없음 → SCE 고유. 단 저빈도 | 주석 |
| **손익** (매출·영업이익·순이익) | **IS** | — | — |

**한 줄 원칙: 잔액=BS · 현금흐름=CF · SCE 는 "현금 안 움직이는 자본 내부 이동"만 보조.**

## 1. 왜 SCE 를 잔액의 1차 출처로 쓰지 않는가 (실측 근거)

### 1-1. SCE 원문오류는 100% '기말잔액 행'에 있다
```
SCE 이상치 5,600건 위치:  기말잔액행 5,600 · 기초잔액행 0 · 변동사유행 0
```
**변동사유 행(배당·자사주·순이익 등)에는 이상치가 단 한 건도 없다.** 오류는 오직 기말 '잔액'에
몰려 있고, 그 잔액은 BS 가 정상값으로 갖고 있다. → 잔액을 BS 에서 가져오면 SCE 오류 5,600건이
**전량 무해화**된다(그 값을 애초에 SCE 에서 안 꺼냄).

### 1-2. 오류 유형 (SIGN 638·자릿수 18·단위 71, `10_16` 아님 이 보고서 §3)
- SIGN(부호): 결손금을 괄호 없이 양수 표기 등. 잔액이라 BS 로 대체 가능.
- 단위 오표기: 표제 '백만원'인데 실제 '원'(HLB제약 등 71보고서). BS 도 같이 부풀 수 있어
  교차대조로 안 잡히는 종류 → §3 별도 격리 대상.

### 1-3. SIGN 자동판정 시도 3회 전부 실패 (되돌아올 기록)
"SCE 기말잔액의 옳은 부호"를 자동 판정하려 3가지 독립신호를 시도했으나 전부 반례:
- v1 BS 인접3년 부호 → 흑자전환기 오판
- v2 다음해 SCE 기초값 → 다중 기초블록 오매칭
- v3 표내부 기초+변동=기말 → 변동행 필터가 회사마다 불일치
**교훈: SCE 표 구조가 회사마다 달라 '누가 맞는지' 자동판정은 신뢰 불가.**
→ 결론: 자동판정에 매달리지 않는다. 잔액은 BS 를 쓰고 SCE SIGN 은 **격리(held)** 로 둔다.
   대체재(BS)가 있으므로 실질 손실 0.

## 2. 출처 선택의 구현 형태 (초안 — 확정 아님)

계층3 은 (corp, fiscal_year, period, basis) 단위로 지표를 조립한다. 각 지표는
**출처 우선순위 리스트**를 갖고, 첫 번째로 값이 존재+무결한 출처를 채택한다.

```
지표 '이익잉여금':
    출처순위 = [BS.col0, SCE.기말.이익잉여금열]
    → BS 에 정상값 있으면 그것. 없을 때만 SCE 폴백(단 held 표시된 값은 건너뜀).
지표 '배당지급액':
    출처순위 = [CF.배당금지급, SCE.배당행, 주석.배당]
지표 '자기주식소각':
    출처순위 = [SCE.자기주식소각행]   # CF 에 없음
```

⚠ **미해결 — 이 문서가 확정 못 하는 것:**
1. 지표 카탈로그(무엇을 어느 라벨에서 뽑을지)의 **라벨 매핑**. 계층2 는 label_raw 원문 그대로라
   'X.영업이익'·'영업이익(손실)'·전각공백 변이를 계층3 이 정규화해야 한다. 이게 계층3 의 본체.
2. 출처 간 **값이 다를 때**(오류 아닌 정상 불일치 — 연결범위·재작성) 어느 걸 믿을지.
3. 보정(`report_line_corrections`) 적용 시점 — 계층3 적재 시 1회(권고, 전문가) vs 뷰.

## 3. 원문오류 처리 방침 (확정)

전문가 자문 + 사용자 결정 종합:
- **report_lines.value_won 은 절대 안 고친다.** 원문 대조 회귀(현재 399/400) 유지.
- 보정은 `report_line_corrections`(규칙 저장소, 스키마 완성·미가동)에만 기록.
- **대다수는 보정 대신 격리.** 잔액 SIGN 은 BS 대체로 실질 무해 → held.
- **high 확정분만 선별 보정**, 단 적용 전 표본 원문대조로 정밀도 실측(전제조건).
- **단위오류 71건은 아직 탐지경로 없음**(BS·SCE 동반 부풀어 교차대조 불가) → §미해결.

## 4. 불확실성 지도 — 되돌아올 지점 (★사용자 우려 대응)

2015+ 에서 **확실히 정리된 것**과 **아직 불확실한 것**을 명시한다. 불확실한 채로 pre-2015 로
넘어가면 안 되는 항목에 ⚠ 표시.

### 확실 (2015+ 기준 데이터로 검증됨)
- ✅ 계층2 원문 전사 무결성: 원문대조 399/400, SCE BS교차 679/0 FAIL
- ✅ 잔액 출처 = BS: SCE 이상치 100% 기말잔액행 → BS 대체로 무해화
- ✅ 배당·자사주취득 = CF·SCE·주석 3중 존재, 값 일치(삼성 실측)
- ✅ SCE 고유가치 = 자기주식 소각·자본 내부이동(현금 무이동분)

### ⚠ 불확실 — 계층3 착수 전/중 해소 필요
- ⚠ **라벨 정규화 규칙 부재.** 계층3 의 본체인데 아직 카탈로그 없음. 이게 안 서면 지표 자체를
  못 뽑는다. → 계층3 1순위 작업.
- ⚠ **단위오류 71건 탐지경로 없음.** BS·SCE 동반 부풀어 현재 자동탐지 불가. 절대임계
  (자산총계 ≥ 국내최대기업)로 격리 후보를 만들 수 있으나 중간대역 누수. → 계층3 진입 전 결정.
- ⚠ **주석 미적재.** 배당·이익잉여금처분의 표준출처인데 계층2 1차는 본문만. 주주환원 지표의
  완결성에 필요. → 별도 단계(볼륨 5배).
- ⚠ **출처 간 정상 불일치 판정.** 소급재작성·연결범위변동으로 BS↔SCE 가 달라지는 정상 케이스와
  원문오류의 구분. OTHER/low 4,574건에 혼재. → 계층3 에서 유형 재분류.

### 되돌아오는 트리거
위 ⚠ 중 하나라도 계층3 진행 중 "표준화 가정이 깨진다"고 판단되면 **즉시 이 문서로 복귀**,
2차 패스(pre-2015) 착수 전에 재정비. pre-2015 는 서식이 더 이질적이라(2009~13 `<P>` 구분자,
2000~08 미확인) 2015+ 에서 미해결인 항목은 거기서 반드시 악화된다.
