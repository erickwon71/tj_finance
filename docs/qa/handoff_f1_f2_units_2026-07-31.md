## 4. ★사용자 결정이 필요한 것 3건 (재적재 전에)

### D1. 미선언 표의 단위 상속 — 약 **4.9M 셀**이 걸려 있다

원문 실측 서식:
```
<P> (1) … 범주별 금융상품의 내역은 다음과 같습니다.<당분기말>
<TABLE> (단위: 천원)      ← 선언만 담은 표
<TABLE> [자산 데이터표]    ← 단위 획득 O
<P> (빈 요소)
<TABLE> [부채 데이터표]    ← ★미선언으로 value_won 비게 됨(콤마금액 27~29 셀)
```
같은 선언 아래 **두 번째 데이터표부터** 단위를 잃는다. 미선언 데이터표 셀의 **53%** 가 이것이다.

| 안 | 내용 | 위험 |
|---|---|---|
| ① 현행 유지 | value_raw 만 보존 | 금액 4.9M 셀이 계층3 에서 못 쓰인다 |
| ② 항목 내 상속 | 항목 경계 안의 선언을 상속 | 헤더가 침묵하는 주식수 열이 ×1,000 |
| **③ 선언표 한정 상속(권고)** | **데이터 없는 '선언 전용 표'가 앞에 있을 때만** 상속 | 위 서식만 정확히 겨냥 |

### D2. `undetermined` 열을 어디까지 채울 것인가

혼합 선언 + 열 헤더가 침묵하면 지금은 NULL 이다(note 행의 1.0%). '당기/전기' 같은 **기간
표지를 금액 근거로 인정**하면 대부분 채워지지만, `'(단위: 주, 원)'` 주식선택권 표의 기초/기말
열이 주식수라 오염 위험이 있다. 현행은 **안 채우는 쪽**.

### D3. 수주 진행률형(4.3%)·잔고 0 행(1.7%) 을 적재할 것인가

`수주총액 × (1 − 진행률/100)` 파생은 반올림 오차가 있고, 잔고 0 행은 값이 0 이지만
수주총액·기납품액은 실데이터다. 둘 다 **정보 대 신뢰도**의 문제라 사용자 판단이 맞다.
