## 1. 전체 구조 한눈에 보기

앱은 좌측 **사이드바**(모든 화면 공통 설정)와, 상단 네비게이션으로 전환하는 **8개 페이지**로 구성됩니다.

| 아이콘 | 페이지 | 한 줄 요약 |
|---|---|---|
| 📈 | 기업 시각화 | 개별 기업의 재무제표·지표·밸류에이션·주가·생산·지분 등 9개 탭 (기본 화면) |
| 🔎 | 스크리너 | 조건에 맞는 기업을 전수 검색(필터·정렬·다단계 좁히기) |
| 📊 | 분기 변화 | 전 기업의 분기별 매출·영업이익 증감을 한 표로 비교 |
| 💎 | 밸류에이션 | 선택 기업의 DCF(내재가치)·배당 분석 |
| ⚖️ | 기업 비교 | 여러 기업을 나란히 놓고 핵심 지표 비교 |
| 🧪 | 자유조합 차트 | 원하는 지표를 자유롭게 조합(비율·차분·주당)해 그래프 생성 |
| 🗂 | 보고서 수집 | 신규 공시 탐지→다운로드→조회 가능하게 반영을 원클릭 실행 |
| ℹ️ | 도움말 | 각주(주1·주2·주3)·연결/별도·달력분기 개념 설명 |

**공통 규칙**:
- 금액은 원래 원(KRW) 단위 값이며, 화면에는 보기 편하도록 억원/조원 단위로, 비율은 %로 자동 환산되어 표시됩니다. CSV로 내려받을 때는 원 단위 그대로 받을 수 있습니다.
- 좌측 사이드바의 **"기업 검색"으로 고른 기업(포커스 기업)**을 기업 시각화·밸류에이션·자유조합 차트 페이지가 공유합니다. 스크리너·분기 변화 페이지에서 표의 행을 클릭해도 포커스 기업이 바뀝니다.
- 좌측 사이드바의 **연결/별도**, **연간/분기** 설정은 대부분의 페이지에 전역으로 적용됩니다.

## 2. 좌측 사이드바 (모든 화면 공통)

### 2.1 기업 검색
- 텍스트 입력창에 **기업명 또는 종목코드**(예: `삼성전자` 또는 `005930`)를 입력.
- 검색 결과가 **1개**면 자동으로 그 기업이 선택됩니다.
- 검색 결과가 **여러 개**면 라디오 버튼 목록이 뜨고, 원하는 항목을 고른 뒤 **[선택]** 버튼을 눌러야 확정됩니다.
- 결과가 없으면 "검색 결과 없음"이 표시됩니다.

### 2.2 ⭐ 관심종목
- 관심 기업을 등록해두고 빠르게 다시 열 수 있는 목록입니다(기본은 접힘, 등록된 기업이 있으면 펼쳐짐).
- 등록은 **기업 시각화 페이지 상단**의 **☆ 관심추가 / ⭐ 관심해제** 버튼으로 합니다.
- 목록의 각 항목은 **[기업명 · 종목코드]** 버튼(클릭 시 그 기업으로 즉시 이동)과 **[❌]** 버튼(관심종목에서 제거)으로 구성됩니다.
- 한 번 등록해두면 앱을 껐다 켜도 목록이 그대로 유지됩니다.

### 2.3 표시 옵션 (전역)
- **재무제표**: `연결` / `별도` — 라디오로 전환. 대부분 페이지가 이 값을 기준으로 조회하되, 해당 기준의 데이터가 없으면 자동으로 반대 기준으로 대체되고 그 사실이 안내 캡션으로 표시됩니다(부록 B의 **주2** 참고).
- **기간**: `연간` / `분기` — 라디오로 전환. `연간`은 회사가 실제 보고한 회계연도(FY) 원본, `분기`는 달력분기(CQ1~CQ4)로 재배치한 값입니다(부록 D 참고).

### 2.4 DB 상태 (접힌 expander)
- 펼치면 DB 연결 여부와 **활성 보통주 수 / 재무행 수 / 주가행 수**를 확인할 수 있습니다. 연결 실패 시 오류 메시지가 표시됩니다.

## 3. 📈 기업 시각화

가장 핵심적인 화면으로, 기업 하나를 골라 재무·지표·밸류에이션·주가·생산·지분 등을 9개 탭으로 봅니다.

### 3.1 화면 상단 공통 요소 (탭과 무관하게 항상 표시)
| 요소 | 설명 |
|---|---|
| 기업명 헤더 | 기업명(종목코드) · corp_code · 시장. 특별 조치가 있으면 옆에 **(주1)(주2)(주3)** 각주가 붙음(부록 B) |
| ☆/⭐ 버튼 | 헤더 우측. 관심종목 추가/해제 |
| 📄 공시 원문 보기 (접힌 expander) | 셀렉트박스로 사업·반기·분기 보고서 중 하나를 고르면, **[DART에서 원문 보기 ↗]** 버튼(DART 웹뷰어로 이동)과 **[원문 파일 내려받기]** 버튼(로컬에 저장된 원본 XML)이 나타남 |
| 신뢰 배지 | 표시된 값이 공시 보고서 원문과 일치하는지 확인한 결과를 한 줄로: ✅ 통과 / 🔎 검토대상 / ⚠ 확정 불일치 |
| 🔄 기재정정 이력 배지 | 해당 기업 기간 중 기재정정 공시가 있었으면 표시. "DB 반영 N / 원본유지 N" + 펼치면 기간별 상세표(부록 B 참고) |
| ⚠ 시장조치 이력 배지 | 관리종목·상장폐지·매매정지 등 이력이 있으면 표시(활성 조치가 있으면 붉은 경고, 과거 이력만 있으면 회색 안내) + 펼치면 상세 이력표 |
| ⚠ 이상치 점검 (데이터가 있을 때만, 자동 펼침) | 영업이익률 60%/100% 초과, 매출·이익 급증(전년 동기 대비 4배↑) 등을 표시용으로 경고. **DB 값 자체는 보고서와 100% 일치가 검증된 상태**이며, 이 경고는 원본 보고서 수치 자체의 이상 가능성을 알리는 용도 |
| DQ 경고 배너 | 기간별 데이터 품질 플래그(DQ=2 경고/DQ=3 오류)가 있으면 표시 |

### 3.2 탭 목록
탭은 상단의 가로 라디오 버튼으로 전환합니다: **📑 재무제표 · 📊 지표 · 💰 밸류에이션 · 🏆 대가지표 · 📈 주가 · 📊 주가·재무 결합 · 🏭 생산·가동률 · 🏢 섹터·피어 · 👔 임원·지분**

#### ① 📑 재무제표 탭
- **표시 기간(구간 선택) 슬라이더**: 전체 보유 기간 중 표시할 구간을 좌우 핸들로 선택(기본은 최근 10개 연도 / 12개 분기).
- 3개 표를 순서대로 표시(모두 **억원** 단위, 가로 스크롤):
  - **손익계산서**: 매출액·매출원가·매출총이익·판관비·영업이익·EBITDA·순이익·지배주주순이익
  - **재무상태표**: 자산총계·유동자산·현금·매출채권·재고자산·유형자산·무형자산·부채총계·유동부채·단기차입금·장기차입금·자본총계·이익잉여금·순부채
  - **현금흐름표**: 영업현금흐름(CFO)·투자현금흐름(CFI)·재무현금흐름(CFF)·CAPEX·잉여현금흐름(FCF)·배당금지급·감가상각비(D&A)
- **[⬇ 재무제표 CSV 다운로드]**: 선택 구간을 **원 단위**(raw)로 내려받음.
- **🔗 이 값의 원천 공시** (접힌 expander): 연도별로 BS/IS/CF 각각이 실제로 어느 공시(rcept 접수번호)에서 왔는지 DART 뷰어 링크로 확인. 기재정정이 부분적으로 있으면 표별로 다른 공시일 수 있음을 보여줌.
- **📄 요약 tearsheet PDF 생성** 버튼: 클릭하면 밸류에이션 스냅샷·재무 요약표·수익성표·매출/이익 추이 차트·ROE/마진 추이 차트를 담은 **A4 1페이지 PDF**가 생성되고, 곧이어 **[⬇ tearsheet PDF 내려받기]** 버튼이 나타남(파일명: `기업명_corp_code_tearsheet.pdf`).

#### ② 📊 지표 탭
- 화면 상단에 **카테고리별 멀티셀렉트**(재무데이터 · 수익성 · 성장성 · 안정성, 2열 배치) — 각 카테고리에서 원하는 지표를 자유롭게 여러 개 고를 수 있습니다(전체 목록은 부록 A).
- 기본 선택값: 매출액·영업이익·영업이익률.
- **표시**: `표` / `그래프` 라디오.
  - **표** 선택 시: 전체 보유 기간을 카테고리별로 나눠 표시 + **[⬇ 지표 CSV 다운로드]**(원시값: 금액=원, 비율=소수).
  - **그래프** 선택 시: 전체 기간이 4개 초과면 **"최근 N개 기간" 슬라이더**로 확대/축소 가능. 금액은 좌측 축(억원), 비율/배수/일수는 우측 축(이중축 차트).

#### ③ 💰 밸류에이션 탭
- **밸류에이션 표**(최신 FY 기준): 시가총액·EV·PER·PBR·PSR·PCR·EV/EBITDA·EV/EBIT·EV/FCF·EPS·BPS.
- **📉 밸류에이션 밴드**(자기 역사 대비, 2015년 이후 일별 데이터):
  - **지표 셀렉트박스**: PER / PBR / PSR / EV/EBITDA / 배당수익률 중 선택.
  - 현재값·역사적 백분위(0~100)·판정(🟢 저평가권 / 🟡 중립권 / 🔴 고평가권)을 메트릭 카드로 표시.
  - 분위 밴드 차트(p10/p25/중앙값/p75/p90 + 현재 마커)로 시각화.
- **📐 주당지표·발행주식수 추이**(연간 FY 기준):
  - EPS/BPS/FCF-per-share 추이 라인차트.
  - 발행주식수 추이(자사주·희석 반영) + **자본이벤트 마커**(증자/감자/CB/BW/EB 발생 연도에 삼각형/다이아몬드 표시, 호버 시 상세).
  - "잠재 희석 %" 캡션(최근 3년 CB/BW/EB 기준 상한선 추정치).
  - **자본이벤트 이력** (접힌 expander): 접수일·이사회결의일·구분·주식수변동·접수번호 표.
- **🕒 자본이벤트 타임라인**: 시간축 위에 이벤트를 종류별 마커로 표시(▲증자 ▼감자 ◆잠재CB/BW/EB ●자기주식) + 점선으로 확정 발행주식 누적 추이.

#### ④ 🏆 대가지표 탭
3열로 나눠 표시(모두 최신 FY 기준):
- **Buffett / Piotroski**: Piotroski F-Score(뱃지), Owner's Earnings, FCF품질(CFO/NI), ROIC, ROIC 5년평균, 배당성향.
- **Graham**: EPS, BPS, Graham Number, Graham 상승여력, NCAV/주가, PER×PBR(≤22.5 기준), EPS 흑자연수.
- **Greenblatt / Lynch / Fisher**: 이익수익률(EY), 투하자본수익률(ROC), PEG(Lynch), R&D/매출(Fisher), 매출총이익률 변화.
- 시가총액이 없으면 "가격기반 지표 제한" 안내가 표시됩니다.

#### ⑤ 📈 주가 탭
- **기간 라디오**: `1Y` / `3Y` / `5Y` / `10Y` / `전체`.
- **로그 스케일** 토글(기본 켜짐).
- **캔들** 토글(끄면 종가 라인, 켜면 캔들스틱).
- 하단에 거래량 막대 차트가 함께 표시됩니다. 장기간 데이터는 자동으로 주간 다운샘플됩니다.

#### ⑥ 📊 주가·재무 결합 탭
- **재무 항목 멀티셀렉트**(최대 3개): 매출액·영업이익·순이익·지배주주순이익·EBITDA·자본총계·잉여현금흐름(FCF)·CAPEX 중 선택.
- **로그 스케일(주가)** 토글.
- 좌축=주가(원), 우축=선택한 재무 항목(억원). 1개 선택 시 막대, 2~3개 선택 시 라인. 기간(연간/분기)은 사이드바 설정을 따릅니다.

#### ⑦ 🏭 생산·가동률 탭
- **가동률(%) 추이**: 부문/품목별 라인차트 + 최신 가동률 메트릭 카드(최대 4개 표시).
- **생산능력 / 생산실적** 표: 부문·품목별, 연도별 컬럼(단위가 항목마다 달라 표로 표시).
- **생산설비 보조지표** (접힌 expander): 표준생산능력·가동가능일수 등 비시계열 보조 데이터.
- **🏗 수주상황** (하위 패널):
  - **수주잔고 다년 추이** 막대차트(2개 연도 이상 보유 시) + 증감률 캡션.
  - 부문별 **수주총액·기납품액·수주잔고** 표.
  - 데이터가 없으면 사유 안내(비수주 업종이거나, 진행률%만 있는 형식이라 v1 범위 밖이거나, 미수집).

#### ⑧ 🏢 섹터·피어 탭
- 업종코드(KSIC 중분류) 기준 **피어 대비 지표 백분위** 표: 지표·기업값·섹터중앙값·백분위·평가(🟢우수/🟡평균/🔴열위).
- **시총 상위 피어** 표: 기업명(★=현재 기업)·시총(조)·ROE·영업이익률·PER·PBR.
- 업종코드가 없거나 섹터 피어 수가 부족하면 안내 메시지가 표시됩니다.

#### ⑨ 👔 임원·지분 탭
- **임원 현황**: 임원 수·등기임원 수·여성 비율 메트릭 + 성명·직위·등기여부·상근여부·담당업무·최대주주관계·재직기간·주요경력 표.
- **대주주/지분 현황**: 최대주주+특수관계인 지분율, 소액주주 지분율(float 근사)·수 메트릭 + 보유자 표(성명·관계·주식종류·기말지분율·기말소유주식수·비고) + **최대주주 변동이력** (접힌 expander).

## 4. 🔎 스크리너

화면이 좌(필터·결과, 5) / 우(선택 기업 시각화, 7) 로 분할되어 있습니다.

### 4.1 💾 저장된 스크린 (접힌 expander, 좌측 상단)
- **저장된 스크린 셀렉트박스** + **[불러오기]**(선택한 구성을 그대로 복원) / **[삭제]** 버튼.
- **새 스크린 이름** 입력 + **[저장]** 버튼: 현재 화면의 모든 설정(기간단위·집계방법·시장·결측처리·패스 수·각 패스의 필터/정렬/한도)을 통째로 이름 붙여 저장.
- 한 번 저장해두면 앱을 다시 열어도 이름으로 다시 불러올 수 있습니다.

### 4.2 기본 설정
| 옵션 | 선택지 |
|---|---|
| 기간 단위 | `연간` / `분기` |
| 집계 기간 | 연간: 1~10년 슬라이더 · 분기: 4~20분기 슬라이더 |
| 집계 방법 | 연간: `평균` / `CAGR` / `YoY` · 분기: `평균` / `CAGR` / `YoY` / `QoQ(전분기比)` |
| 시장 | `전체` / `KOSPI` / `KOSDAQ` |
| 결측값(NULL) 처리 | `제외`(기본, 데이터 없는 기업은 그 필터에서 탈락) / `통과`(결측이어도 그 필터만 통과시킴 — EBITDA·R&D처럼 커버리지 낮은 지표에 유용) |

### 4.3 퀀트 패스 (최대 4개, 순차 적용)
- **퀀트 패스 수** 셀렉트박스: 1~4.
- 각 패스는 접힌 expander이며 다음을 구성합니다:
  - **필터 지표 멀티셀렉트**: 재무/비율 지표(부록 A 전체 50종) + 멀티플(PER/PBR/EV·EBITDA/PSR/PCR) + 대가지표(이익수익률·ROC·마법공식랭크·PEG·Graham상승여력·NCAV/주가·R&D/매출) + 시가총액(조원).
  - 선택한 지표마다 **최소(이상)** / **최대(이하)** 숫자 입력(둘 다 비우면 필터 미적용, 하나만 입력하면 단측 조건, 둘 다 입력하면 구간 조건).
  - **정렬 지표** 셀렉트박스 + **방향**(`내림` / `오름`) + **한도**(1~2,000, 기본 30).
- 패스는 이전 패스의 결과에 순차 적용됩니다(패스1 결과 → 패스2 필터 → …). 여러 패스면 "퀀트 축소: P1 N건 → P2 N건 → …"가 표시됩니다.

### 4.4 실행 및 결과
- **[스크리닝 실행]** 버튼.
- 결과 표(기업명·종목코드·시장·기준·기간 + 선택 지표들). **행을 클릭하면 우측에 해당 기업의 기업 시각화 화면 전체가 표시**됩니다(좌측 결과는 유지됨).
- 흑자↔적자 전환 구간은 성장률(%) 대신 **"흑자전환"/"적자전환"** 라벨로 표시됩니다(수치가 왜곡되어 보이는 것을 방지).
- **[결과 CSV 내려받기]** 버튼.

## 5. 📊 분기 변화

전 대상기업의 매출·영업이익을 분기 단위로 비교하는 화면입니다.

- **달력연도 셀렉트박스**로 연도를 고르고, **Q1~Q4 탭**으로 분기를 전환합니다.
- 각 분기 탭의 표: 기업명·종목코드·시장·기준 + 매출(억)·매출 QoQ 증감(액/률)·매출 YoY 증감(액/률)·영업이익(억)·영업이익 QoQ/YoY 증감(액/률). 기본 정렬은 매출 YoY 증감률 내림차순이며, **모든 숫자 컬럼은 헤더 클릭으로 재정렬**할 수 있습니다.
- **행을 클릭하면 팝업(모달)** 이 뜨며, 다음을 볼 수 있습니다:
  - 최근 16개 분기의 매출·영업이익을 **표 / 그래프**(그룹 막대) 라디오로 전환.
  - **"전체 상세 분석 보기" 토글**을 켜면 기업 시각화 페이지 전체(9개 탭)가 모달 안에 임베드되어 열립니다(분기 기준 강제).
- **[결과 CSV 내려받기]** 버튼(분기별).
- 데이터가 없는 분기는 빈 표로 표시됩니다.

## 6. 💎 밸류에이션

사이드바에서 선택한 포커스 기업의 내재가치·배당을 분석합니다.

### 6.1 📉 DCF 내재가치
- **가정(미입력 시 자동 추정)** 접힌 expander:
  - **FCF 성장률 %**(0=자동 추정)
  - **WACC %**(0=자동 추정)
  - **영구성장률 %**(기본 2.5%)
  - **예측 기간(년)** 슬라이더(3~10년, 기본 5년)
- 결과 메트릭: 주당 적정가·현재가·안전마진(저평가/고평가 델타 표시)·자기자본가치.
- 사용된 가정 요약 캡션(성장률·출처·WACC·영구성장률·베타·기준FCF).
- 연도별 예상 FCF·현재가치(PV) 표 + 영구가치 PV·기업가치·순부채 캡션.
- 계산 불가 시(재무/FCF 데이터 부족) 안내 메시지.

### 6.2 💵 배당 분석
- 메트릭: 연속 배당 연수·3년 평균 수익률·3년 평균 배당성향·DPS CAGR(5년).
- 연도별 표: FY·DPS·배당수익률·배당성향·총배당.
- 배당 데이터가 없으면 안내 메시지.

## 8. 🧪 자유조합 차트

준비된 지표 중 임의의 것을 자유롭게 골라 조합하고, 파생 필드(비율·차분·주당)까지 만들어 시각화하는 화면입니다.

### 8.1 💾 프리셋 (접힌 expander)
- **저장된 프리셋 셀렉트박스** + **[불러오기]** / 프리셋 삭제 버튼.
- **새 프리셋 이름** 입력 + **[저장]**: 기본 지표 선택·파생 필드 목록·오버레이 설정을 통째로 저장.
- 한 번 저장해두면 앱을 다시 열어도 이름으로 다시 불러올 수 있습니다.

### 8.2 📈 기본 지표 선택
- 전체 지표 목록(50종, 부록 A)에서 자유롭게 멀티셀렉트. 각 옵션은 "지표명 · 카테고리" 형태로 표시됩니다.

### 8.3 🧬 파생 필드 조합 (접힌 expander)
- **연산 셀렉트박스**: `비율 (A÷B)` / `차분 (A−B)` / `주당 (A÷주식수)`.
- **A 필드** 셀렉트박스(전체 지표 목록).
- **B 필드** 셀렉트박스(비율·차분에서만 활성 — 주당은 B 불필요).
- **[➕ 추가]** 버튼: 유효성 검사(예: 차분은 금액 필드끼리만, 주당은 금액 필드만, A와 B가 같으면 불가)를 통과하면 목록에 추가되고, 이미 있는 조합이면 경고.
- 추가된 파생 필드는 목록에 "이름 · 단위" 형태로 나열되며, 각 항목 옆 **[❌]** 버튼으로 삭제 가능.
- 단위 규칙: 비율=배수(x), 차분=금액(억원, 금액 필드끼리만 가능), 주당=원/주(금액 필드만 가능).

### 8.4 표시
- **표시 라디오**: `그래프` / `표`.
  - **표**: 전체 기간을 지표×기간 표로 표시 + **[⬇ CSV 다운로드]**(원시값).
  - **그래프**: 전체 기간이 4개 초과면 "최근 N개 기간" 슬라이더로 확대/축소. 금액=좌축, 비율/배수/일수/주당=우축.

### 8.5 📉 주가 결합 (오버레이)
- **"주가 위에 금액 지표 결합" 토글**을 켜면:
  - **결합할 금액 지표 멀티셀렉트**(현재 프레임에 있는 금액계열 중 최대 3개).
  - **로그(주가) 토글**.
  - 좌축=주가(원), 우축=선택 지표(억원). 주가 데이터가 없으면 안내.

## 9. 🗂 보고서 수집

새로 등록된 공시를 찾아서 받아오고, 다른 화면에서 바로 조회할 수 있게 반영하는 화면입니다.

### 9.1 현황 대시보드
- 메트릭: 활성 보통주 수·정기공시 수·받아온 보고서 수·반영 완료된 기업 수.
- 캡션: 최신 공시 접수일, 아직 받아오지 못한 건수.

### 9.2 ① 상장 유니버스 갱신
- **[🔁 유니버스 갱신 실행]** 버튼: 최신 상장 목록과 맞춰서 **신규 상장 기업 추가** + **상장폐지·제외 기업 비활성화**.
- 실행 후 메트릭(현재 대상·신규 반영·제외)과 신규/제외 기업 목록 표(각각 접힌 expander)가 표시됩니다.
- 신규 공시 수집 전에 먼저 실행하면 신규 상장사도 수집 대상에 포함됩니다.

### 9.3 ② 신규 공시 수집
- **탐지 기간(일)** 숫자 입력(1~90, 기본 7일) — 실행일로부터 최근 N일 내 등록된 정기공시를 확인.
- **[🔄 신규 공시 수집 실행]** 버튼: 다음 순서로 진행 상황을 실시간으로 보여주며 처리합니다.
  1. **탐지**: 최근 N일 내 새로 등록된 정기공시를 확인해 대상 기업을 정함.
  2. **확인**: 대상 기업의 공시 목록을 다시 한번 확인.
  3. **다운로드**: 신규 보고서를 받아옴(완료/실패/건너뜀 건수 표시).
  4. **반영**: 받아온 보고서 내용을 화면에서 조회 가능한 형태로 반영. 기업별 진행률 바와 함께 처리되고, 완료 후 처리 건수 요약이 표시됩니다.
- 완료 후 대시보드가 자동 갱신됩니다.
- ⚠ 수집 중에는 화면이 잠시 멈추며(완료 후 자동 갱신), 공시 사이트 응답이나 네트워크 상태에 따라 시간이 걸릴 수 있습니다.

## 부록 B — 각주(주1·주2·주3) 및 신뢰 배지

### 각주
| 각주 | 의미 |
|---|---|
| **(주1)** | 비-12월 결산 기업. 분기·비교 화면 수치는 회사의 회계분기를 **달력분기로 재배치·합성**한 값이라, 회사가 보고한 회계연도(FY)와 기간이 다를 수 있음. |
| **(주2)** | 연결 재무제표를 요청했으나 해당 기업·기간에 연결이 없어 **별도(개별)로 대체** 표시됨. |
| **(주3)** | 관리종목 지정·상장폐지 관련·매매거래정지·불성실공시법인 지정·회생절차 개시 등 **시장조치 이력**이 있음(현재도 미해제된 조치 포함 가능). |

### 신뢰 배지 (Gate B)
기업 시각화 화면 상단에 표시되는, "DB 값이 실제 공시 보고서와 일치하는가"를 나타내는 배지입니다.
- ✅ **통과**: Gate B pass 건수와 함께 표시, 불일치 0건.
- 🔎 **검토 대상**: 휴리스틱 항목에서 재검토가 필요한 건이 있음(fail_b).
- ⚠ **확정 불일치**: 값 확인이 필요한 확정 오류가 있음(fail_a).

### 🔄 기재정정 배지
해당 기업의 재무 기간 중 기재정정(DART [기재정정] 공시) 이력이 있으면 표시됩니다.
- "DB 정정본 반영 N" — 정정된 내용이 실제로 DB 값에 반영된 기간 수.
- "원본유지 N"(있을 경우 경고 색상) — 지연·첨부정정 등으로 정정 내용이 아직 반영되지 않았을 수 있는 기간. 이 경우 **원문 확인을 권장**하는 문구가 함께 표시됩니다.
- 펼치면 연도·기간별 "정정본 반영 / 원본유지" 상세표를 볼 수 있습니다.

## 부록 C — 데이터 내보내기(CSV/PDF) 총정리

| 위치 | 버튼 | 형식 | 내용 |
|---|---|---|---|
| 기업 시각화 › 재무제표 탭 | ⬇ 재무제표 CSV 다운로드 | CSV(원 단위) | 선택 구간의 손익/재무상태/현금흐름 전 항목 |
| 기업 시각화 › 재무제표 탭 | ⬇ tearsheet PDF 내려받기 | PDF (A4 1페이지) | 밸류에이션 스냅샷+재무요약표+수익성표+추이차트 2개 |
| 기업 시각화 › 지표 탭 | ⬇ 지표 CSV 다운로드 | CSV(원시값) | 선택한 지표 전체 |
| 스크리너 | 결과 CSV 내려받기 | CSV | 스크리닝 결과 표 전체 |
| 분기 변화 | 결과 CSV 내려받기 | CSV | 선택 연도·분기의 전 기업 매출·영업이익 증감 |
| 자유조합 차트 | ⬇ CSV 다운로드 | CSV(원시값) | 선택 지표 + 파생 필드 전체 |

## 부록 D — 용어 설명

- **연결(consolidated)**: 지배기업과 종속기업을 하나로 합친 재무제표. 그룹 전체 실적.
- **별도/개별(separate)**: 지배기업 단독 재무제표. 종속기업이 없거나 연결을 작성하지 않는 기업은 별도만 존재.
- **달력분기(CQ1~CQ4)**: 1~3월=CQ1, 4~6월=CQ2, 7~9월=CQ3, 10~12월=CQ4. 결산월이 다른 기업들을 같은 시점 기준으로 비교하기 위해 회계분기를 재배치한 것.
- **FY(회계연도)**: 회사가 실제 보고한 사업연도 원본. "연간" 탭이 보여주는 값.
- **TTM**: 직전 4개 분기 합산(Trailing Twelve Months). 분기 화면의 멀티플·대가지표 계산 기준.
- **Gate B**: 화면에 표시되는 재무 값이 실제 공시 보고서 원문과 일치하는지 자동으로 대조·확인한 결과를 가리키는 표시입니다.
- **잠재 희석**: 전환사채(CB)·신주인수권부사채(BW)·교환사채(EB)가 미래에 전부 주식으로 전환된다고 가정했을 때의 상한선 추정 희석 비율(실제 전환/상환 여부는 반영하지 않음).
- **DQ(Data Quality)**: 화면에 표시되는 데이터 품질 경고 표시. 1=정상, 2=경고, 3=오류(재무제표 항등식 불일치 등).
