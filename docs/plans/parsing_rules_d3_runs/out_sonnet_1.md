### R159-보강⑤
> **규칙** 계층3 보정은 천원 선언 표에 원 단위까지 소수 3자리로 인쇄된 진짜 소수 셀(`_DOT_GROUPED_RE` 에 걸려 R160 이 결측으로 남긴 것)을, `_SOURCE_TYPO_CELL_FIXES` 에 쉼표를 뺀 형태로 등재해 `parse_amount`(R157, Decimal)가 ×1,000 한 정확한 원 값으로 `layer3_cell_corrections` fill(`R159_typo`)로 채운다. 천원 × 소수 3자리 = 정확한 원이라 반올림하지 않는다. 계층2 는 결측 그대로다.
> **판정 예** CJ제일제당 `20260316001116`(2025 사업보고서) 연결 손익계산서 `(571,455,619.874)`→`(571455619.874)` = −571,455,619,874 원, `(322,517,146.659)`, `(248,938,473.216)` 같은 방식(지배기업 소유주 귀속 당기순이익(손실)·계속·중단 3행). 근거: 당기순이익 (416,955,408) = 지배 (571,455,619.874) + 비지배 154,500,212(천원 반올림), 계속 (322,517,146.659) + 중단 (248,938,473.216) = (571,455,619.875).
> **하지 않는 것** 반올림하지 않는다. 계층2 에 값을 쓰지 않는다(R0-2).
> **코드** `_SOURCE_TYPO_CELL_FIXES`, `parse_amount`(R157); 회귀 `tests/test_r159_cj_exact_decimal_cells.py`; 재적재는 이 필링 1건 + 00635134 계층3 재빌드.
> **충돌·불명확** 본문이 판단 근거로 든 합계 산수에서 (571,455,619.874) 가 `계속+중단 = (571,455,619.875)` 와 0.001(천원 단위) 차이 나는데, 이 차이를 허용하는 오차 기준은 적혀 있지 않다.
