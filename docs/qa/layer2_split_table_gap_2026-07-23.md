가 빈 `groups` 반환.

## 2. 근본원인 — 분류와 데이터가 다른 표에 있다
`_detect_body_statement_tables` 는 **한 표가 (a)BS/IS/CF 로 분류 AND (b)데이터행 보유** 여야
통과시킨다. 이 서식은 재무제표 하나가 **3개 표로 분리**된다:
```
[1] '연 결 재 무 상 태 표'           분류=BS   데이터=False   ← 제목만
[2] '제70(당)기 2015년 12월 31일 현재…'  분류=None 데이터=True    ← 실제 숫자
[3] '과 목  주석 제70기…'             분류=None 데이터=False   ← 컬럼헤더
```
- 제목표[1]: 분류 OK 이나 `_table_has_data_rows`=False → 탈락.
- 데이터표[2]: 데이터 OK 이나 `classify_statement_in_body_section`=None(제목이 날짜) → 탈락.
→ 살아남는 group 0 → 빈 결과 → 0행.

정상 서식은 [제목+단위+데이터]가 한 표(또는 제목표 바로 뒤 데이터표가 코드가 기대하는 형태)라
통과한다. 이 서식은 **재무제표명 자체가 별도 표**로 떨어져 있는 변형이다.
