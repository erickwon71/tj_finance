# 판정 시험 사례 (모든 금액은 표시 단위 백만원, 원문 선언도 백만원. D=DB, S=원문)

1. SCE 연결 당기 블록 '이익잉여금' 열: 기초 100, 변동행 +30, (10), 기말 120. 모든 셀 D=S. 기계 발견 sce_identity 로 올라옴.
2. 1번과 같은데 기말이 원문·DB 모두 121.
3. 1번과 같은데 기말이 원문·DB 모두 125.
4. SCE '이익잉여금' 열: 기초 100, '배당금 지급' 원문 셀 "10"(괄호 없음), DB 값 -10, 기말 90(D=S). 이 셀이 들어간 다른 항등식은 없음. 기계 발견 value 로 올라옴.
5. 4번과 같은데 기말이 원문·DB 모두 95.
6. IS '매출액' 원문 1,234, DB 1,234,000 (CSV 단위 백만원). 기계 발견 value.
7. 기계 발견 zero_row 1건.
8. 기계 발견 sign_omitted 1건.
9. BS 연결: 자산총계 1,000, 부채총계 600, 자본총계 398. 모두 D=S. 기계 발견 bs_identity.
10. IS 한 행: 원문 계정명 '영업수익' 값 500, DB 계정명 '매출액' 값 500. 기계 발견 value.
11. SCE 셀: 원문 "50", DB -50. 이 셀이 든 행 합계(⑤)는 D 로 닫히고 S 로 안 닫힘. 그런데 그 열 롤포워드(①)는 S 로는 차이 20, D 로는 차이 120.
12. 원문 IS 에 '기타수익 300' 행이 있는데 DB 에 없음.
13. 한 필링에 value 발견 15건. 표본 3건을 확인했더니 2건은 C3, 1건은 C2(파서 복원).
14. 필링의 기계대조 줄이 stale.
15. fixed 이슈 재확인: 기계 자동 sign_flip, source_value_raw "1,000", 현재 DB -1,000, 그 열 롤포워드는 현재 DB 값으로 정확히 닫힘(다른 항등식 악화 없음).
16. 기계 발견 unmatched_table, 그 표는 이익잉여금처분계산서.

각 사례에 대해 한 줄로 답하라: `번호 | 적용한 표의 행(C1/C2/C3/I1/I2/I3/없음 등) | 행동(이슈 없음 / 이슈 등록 / 기계오탐 노트 / 아무것도 안 함 / 하나씩 확인 / 대조 안 함 / close / reopen) | error_type(등록 시)`
