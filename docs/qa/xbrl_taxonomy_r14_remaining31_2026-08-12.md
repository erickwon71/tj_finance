## 2. DART 서버 원본 소실(2건) — 남양유업(00107598)

이 필러는 진짜 IFRS taxonomy(`xmlns:ifrs="http://xbrl.iasb.org/taxonomy/2010-04-30/ifrs"`)를
쓰고, R14가 확장한 패턴과 정확히 일치한다 — 그런데도 실패한다. 원인을 직접 추적한 결과,
로컬 인스턴스가 가리키는 공유 entry point
(`http://dart.fss.or.kr/Resource/Taxonomy/ifrs/2010-04-30/dart_entry_point_2010-04-30.xsd`)를
직접 fetch하면 **DART가 XSD 대신 404 에러 HTML 페이지를 반환**한다
("요청하신 인터넷주소(URL)을 찾을 수 없습니다") — 확정. IFRS taxonomy의 **최초 vintage
(2010-04-30)** 자체를 DART가 더 이상 서빙하지 않는 것으로 보인다(2013-03-31 이후
vintage들은 전부 정상 서빙 확인됨). 외부 서버 의존성이 죽은 것이라 우리 코드로 해결 불가.

## 3. filings 메타데이터 불일치(1건) — 에이전트AI(00367695)

`filings.period_end_date` = 2015-03-31(Q1)인데, 실제 XBRL instance에 태깅된 Assets/
Liabilities/Equity/ProfitLoss 등 모든 context의 instant/end_date는 **2013-12-31 /
2014-12-31 / 2015-12-31**(전부 12월 결산 연말)뿐이다 — 2015-03-31에 해당하는 context가
아예 없다(원문 직접 확인, facts 1,449개 전수 스캔). `_resolve_columns()`가 col0

이 트랙과 무관, 후속 조사 필요시 별도 이슈로 추적할 것.
