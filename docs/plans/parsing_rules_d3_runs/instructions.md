# 과제: 규칙 머리 요약 블록 쓰기

입력 파일의 각 절(`=== R번호 | 파일:줄 ===` 로 시작)은 한국 상장사 재무보고서 파싱 프로젝트의 규칙 한 건 **전문**이다.
절마다 아래 형식의 요약 블록을 쓴다. 목적: 서로 다른 모델이 이 블록만 읽고도 **같은 셀에 같은 판정**을 내리게 하는 것.

## 지금 유효한 원칙 (2026-10-12, 이것이 본문의 옛 문구보다 우선한다)
- 계층2(`report_lines`) = 원문에 **인쇄된 숫자를 그 표의 선언 단위로 읽은 값 그대로**. 허용되는 것은 "읽는 법"뿐: 괄호·△·마이너스=음수, 마침표 천단위 구분자(R158·R158-b), 쪼개진 숫자 잇기(R202), 이어붙은 EPS 나누기(R218), 증명된 실제 단위(R169·R207·R238, 숫자는 그대로).
- 인쇄값과 **다른 값**(부호 복원·숫자 교정·빈칸 채움·행 이동/삭제·다른 원천 덮어쓰기)은 **계층3 에서만**, `layer3_cell_corrections`(value·fill·drop)로. 코드가 `fin2/extract` 에 있어도 `as_printed` STEP 뒤에서 계층3 보정으로만 나간다.
- 본문에 "판정 기준은 R0-1 … R0-1 이 이긴다" 또는 "정합화 대기" 같은 문구가 있으면, 2015+ 에서는 **R0-2 로 대체된 문구**다. 그 문구로 규칙을 바꾸지 말고, 본문의 규칙 자체를 요약한다.
- 각 절의 `> **상태** … · **적용 계층** …` 줄이 그 규칙의 계층이다. 적용 계층이 3 이면 규칙 문장을 "계층3 보정은 …" 으로 시작한다(계층2 에는 인쇄값이 그대로 남는다는 뜻).

## 형식 (절마다 정확히 이 모양, 한국어)

```
### R번호
> **규칙** 명령형 1~3문장. 언제(조건) 무엇을(동작) 하는지. "~한다 / ~하지 않는다".
> **판정 예** 본문에 나온 실제 사례 1~2개: 입력(원문 셀·rcept) → 결과.
> **하지 않는 것** 비슷해 보이지만 이 규칙이 적용되지 않는 경우(본문에 적힌 것만).
> **코드** 본문에 적힌 파일::함수 (없으면 생략)
> **충돌·불명확** 본문 안에서 서로 어긋나는 문장, 조건이 빠져 판정이 갈릴 수 있는 곳 (없으면 이 줄을 쓰지 않는다)
```

## 지켜야 할 것
1. **본문에 있는 내용만** 쓴다. 추측·일반화·새 조건 금지. 숫자·rcept·함수명은 본문 그대로 옮긴다.
2. 조건은 빠짐없이 쓴다(허용오차, "정확히 하나", "모든 셀" 같은 한정어를 떨어뜨리지 않는다).
3. 본문에 "기각", "폐기", "되돌림", "보류"로 적힌 변형(예: R197-a)은 규칙에 넣지 말고 "하지 않는 것"에 적는다.
4. 후속 소절(### …-b, 보강 등)이 같은 절 안에 있으면, 지금도 유효한 것은 규칙에 합쳐 쓴다.
5. 판정이 본문만으로 정해지지 않으면 "충돌·불명확"에 적는다 — 스스로 결정하지 않는다.
6. 출력은 블록들만, 입력 순서대로. 다른 설명은 쓰지 않는다.
