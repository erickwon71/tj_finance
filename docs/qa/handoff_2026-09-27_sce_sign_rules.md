## 2. 측정 방법 — 꼭 지킬 것
1. **재추출은 실제 적재와 같은 조건으로**: `include_notes=True` + `load_prior_evidence()`(BS·IS). 주석을 빼면 R162-d 결과가 달라진다(R184 측정 정정 사례).
   도구: `scripts/sce_onoff_tools_2026-09-27/dryrun_full_on.py <in.jsonl> <out.jsonl>`(입력 = 줄마다 `{"rcept": ...}`).
   규칙을 끈 비교판은 `def work(rc):` 첫 줄에 monkeypatch 를 넣어 만든다(예: `_rl.repair_sce_sibling_cells = lambda lines, *a: []`).
2. **새 가드는 켬/끔 재추출로 규모를 잰 뒤 커밋**한다. R186 첫 설계는 표본 3건으로는 맞아 보였지만 전사로는 배당 3,272셀을 되돌렸다.
3. **악화 판정은 롤포워드 + 행 항등식만으로 하지 않는다.** 형제 합계 열 미수정을 악화로 잡는다(R187 64셀 중 60셀 이상이 착시).
   외부 증거(BS 잔액, IS, 직전 보고서)로 확인한다. 도구: `drift_identity_full.py`(두 기준 판정, 첫 인자 = 이 도구 폴더), `cmp_onoff.py`, `show_col.py`.
4. **판정에 쓴 근거를 다시 검증 기준으로 쓰지 않는다**(순환). 예: IS 로 거부한 뒤 "IS 불일치 0" 은 증거가 아니다.
5. 재적재는 반드시 `vq.py batch add-targets` → `batch reload --sd`(대량이면 `--shard 0/3,1/3,2/3` — 샤드는 0부터)로 한다.
   lease 로 보류된 필링은 강제로 풀지 말고 다시 reload 한다.
