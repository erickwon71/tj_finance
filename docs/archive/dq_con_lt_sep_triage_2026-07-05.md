# C2 — Consolidated < Separate 자산총계 트리아지 (2026-07-05)

## 대상
정상적으로 연결 자산총계 ≥ 별도(연결이 종속기업 총자산 편입). `con < sep` 는 이례적이라
per-case 트리아지 대상. 전수 `con.total_assets < sep.total_assets` 는 **14,525행**이나 대부분
① 음수 연결(13, sign 버그) ② ×10^6 별도(26, 단위) ③ 0/극소 연결(57, 추출 미스) = 명백한
구형/추출 아티팩트. 로드맵의 "22 true-magnitude-error" = **최근·양수·유의미 갭**:
`con>0 ∧ sep>0 ∧ sep≤1000조 ∧ con < sep×0.5 ∧ FY ∧ fy≥2015` = **21행**.

## 결론 / 후속
- **~10행 = irreducible LEGIT**(신탁회계) — 차단 대상 아님. 향후 DQ 는 con<sep 를 무조건 fail
  로 보면 안 됨(신탁/증권/지주 예외 존재).
- **~8행 = 실제 추출 버그** — 지배적 원인은 **별도 ×1000 단위 오탐**(Track B 섹션-단위 오검출,
  표준화 max-abs 선택이 부풀린 값 채택). 근본수정 = 단위검출/선택 규칙(design-heavy, memory
  "별도 버그클래스, 후속"). **즉효 = C3 DQ 어서션으로 격리·플래그**(신탁 등 LEGIT allowlist).
- **~3행 = 애매 2015** — 저가치·저우선, 정당 추정.

→ **C3 에서 `con_lt_sep` DQ 어서션 추가**: `con < sep×0.5`(FY, 양수, sep≤1000조) 를 플래그하되
   trust/증권 등 known-legit 은 화이트리스트. 신규 발생분을 자동 포착(현재 21행 = 기준선).
